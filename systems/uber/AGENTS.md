## この題材に固有の規則（開発リポジトリで守る）

### 配車と割り当て

- ドライバーを乗車に割り当てる書き込みは、trips のサービスの 1 つの遷移関数だけで行う。割り当てには、ドライバーごとの fencing token（`assignment_epoch`）を付け、`(region_gen, assignment_epoch)` の組で比べる。古い組の要求は拒否する（ADR-0003、ADR-0021、ADR-0039）。
- 配車の索引（メモリ上のドライバーの位置）は、正本ではない。索引の情報だけで、割り当てを確定しない（ADR-0002、ADR-0003）。
- 配車のアルゴリズムを変えるときは、記録した需要と供給の列を再生するシミュレーションで、変更前と比べる。比べる指標は、配車の成立率、迎車時間、ドライバーの空車時間、二重割り当ての件数（0 件であること）とする（ADR-0004）。
- 配車の計算は、同じ入力と同じ乱数の種から同じ結果を出すように書く。時刻・乱数・外部の ETA は、差し替えられる引数として渡す。本番の判断の入力は、再生できる形で記録する。

### 運賃とお金

- 金額は円の整数で扱う。浮動小数点で運賃を計算しない（ADR-0001）。
- 運賃の規則（認可運賃、事前確定運賃の係数、迎車料金、変動の幅）は、地域と有効期間を持つ版つきのデータにする。コードに直接書かない。法務と運輸局の確認が済んでいない規則は、legal のフラグの裏に置く（下の「フラグ」）。
- 乗客への請求と事業者への精算は、どの層でも冪等にする。同じ乗車で 2 回請求しない。
- 変動する運賃（事前確定型変動運賃など）は、法令と認可が認める地域・幅・方法の中だけで有効にする。幅を超える値は、計算の段階で拒否する。

### 位置とプライバシー

- 乗客とドライバーの正確な位置は、乗車の相手と、その乗車の間だけに見せる。乗車の前と後に、相手の正確な位置を返す API を作らない。例外は乗車の共有と事業者の稼働の地図の 2 つだけで、どちらも `legal.l4.*` のフラグの裏に置く（NFR-009）。
- 位置の生の軌跡は、保持の期間を持つストアだけに置く。ログ・トレース・エラーの報告に、緯度経度を平文で書かない。調査で使うときは、H3 のセルに丸めた値を使う。
- 位置の軌跡を人が見る操作（サポート、事故の調査）は、理由の入力と監査ログを必須にする。
- テストとシミュレーションでは、合成した軌跡か、匿名化して丸めた軌跡だけを使う。実在の人の軌跡をテストのデータに入れない。

### フラグ（ADR-0043）

- フラグは release・ops・legal の 3 種類に分ける。法務の確認待ち（[docs/intent.md](docs/intent.md) の L1〜L9）の経路は、`legal.<L番号>.<feature>` のフラグの裏に置く。release フラグで代えない。
- **legal のフラグを本番で有効にするには、`legal_gate_records` に法務の結論の記録が要る。** 記録の範囲（L 番号・事業者・交通圏・機能・期間）の外を有効にする配備は、AppConfig の検証の関数が拒む。記録は法務の担当だけが作る。エージェントは記録を作らず、legal のフラグの本番の値を変えない。

### 安全の機能

- **緊急の入口（盾の印、110・119 の発信の案内）には release フラグを置かない。** どの画面からも 1 回の操作で開け、フラグの取得やサーバーに失敗しても出す。止められるのは運用への知らせの経路などのサーバーの部品だけ（ADR-0043）。
- 乗車の共有とドライバーの本人確認（顔の照合）は、法務の確認（L4）を要する。release フラグは置かず、`legal.l4.*` のフラグの裏に置く。記録のある範囲では既定で有効にする。
- 障害のときも、緊急の通報の経路（110・119 への発信の案内）を端末の側だけで出せるようにする。
- 安全の機能の変更は、区分「安全」として、変更単位の `quality.md` を必須にする。

## このリポジトリでの規則

- ADR を追加・更新したら、`docs/decisions/README.md` の一覧を生成し直す。
- 本家の振る舞いや日本の制度に寄せた記述には、確かめた出典（確認した日付つき）か「未検証」を書く。
- 本家の名前を、ドメイン・ヘッダー・API の名前空間・ID の接頭辞に使わない。`<brand>` と書く（[リポジトリ共通の ADR-0006](../../docs/decisions/0006-brand-neutral-identifiers.md)）。出典の説明に本家の名前を書くのはよい。
