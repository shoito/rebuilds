# ADR-0053: ログインはパスキー第一、認証の変更の後 72 時間は出金を止める

## Context

交換業者の口座を乗っ取られると、預けた暗号資産がすぐに出ていき、取り戻せない。

- intent はログインをパスキー、予備を TOTP とする。API キーの出金の権限は PM の判断待ち（P2。推奨：持たせない）。
- [ADR-0008](0008-withdrawal-pipeline-and-approvals.md) は、認証の情報の変更の後 72 時間は出金を受け付けないとし、値と契機をこの領域で確定するとした。宛先の待ち 24 時間（P4）は withdrawals の領域が持つ。
- 取引の API は、マーケットメイカーの自動の売買で使う。署名の検査は `trading-api` で、受け付けの p99 20ms（NFR-001）の中で済ませる。
- メルカリの題材が、パスキーと端末の鍵のセッション、重要な操作の強い確かめと振込の待ちを設計した（[ADR-0066](../../../mercari/docs/decisions/0066-sign-in-sessions-and-devices.md)、[ADR-0067](../../../mercari/docs/decisions/0067-account-takeover-step-up-and-payout-holds.md)）。

## Options

予備のログインと回復：

1. **予備はメールの確認と TOTP の 2 つ。回復は eKYC のやり直しで、確かめた本人が口座の本人と一致したときだけ**
2. 予備は SMS の一時コード、回復はメールのリンク
3. パスワードと TOTP

API キー：

- a. **利用者の Ed25519 の公開鍵を登録し、本システムは秘密を持たない**
- b. 本システムが HMAC の秘密を発行し、暗号化して保管する

## Decision

1 と a を採用する。

- ログイン：パスキー（UV 必須）が通常。予備はメールのリンク（15 分、1 回）と TOTP の両方。パスワードと SMS のログインは持たない。
- 回復：`jpki` か `ic_chip_face` で eKYC をやり直し、確かめた値から作る `person_key` が口座のものと一致したときだけ、新しいパスキーを登録させる。
- 重要な操作（出金、宛先の登録と変更、パスキーの追加、TOTP の再設定、メール・電話番号の変更、API キーの作成、退会）は、直近 5 分のパスキーの確かめを求める。
- 出金の待ち：パスキーの追加、TOTP の再設定、メール・電話番号の変更、回復の後 **72 時間**、暗号資産と日本円の出金を受けない。売買と入金は止めない。終わりの時刻を `cooldowns` に持ち、出金の依頼のたびに確かめる。
- 知らせの「これは私ではない」で `frozen`（`takeover_lock`）を立て、全セッションを消す（[ADR-0052](0052-account-lifecycle-levels-and-restrictions.md)）。
- API キー：権限は `read` と `trade` だけ。ヘッダーは `<Brand>-Key`・`<Brand>-Timestamp`・`<Brand>-Signature`、時刻の差 30 秒まで。キーの ID は `<brand>_live_` で始める。期限 365 日、口座ごとに 10 本、任意の IP の許可の一覧。
- セッションの形（端末の鍵で署名する回す更新のトークン、15 分のアクセスのトークン）はメルカリの題材の ADR-0066 を引き継ぐ。

### 他の案を選ばなかった理由

- **2**：SIM の乗っ取りとメールの乗っ取りだけで口座を取られる。資産を預かる交換業者には弱い。
- **3**：パスワードの使い回しと漏えいの一覧での攻撃を受ける。intent の方式でもない。
- **b**：本システムの DB と鍵が漏れたとき、全部の API キーが使われる。秘密の保管と回転の仕組みが要る。

## Consequences

- 良くなること：
  - メールと電話を取られただけでは、ログインも回復もできない。
  - 乗っ取りの後に認証の情報を替えても、72 時間は資産が出ず、本人が知らせで気づける。
  - 本システムの漏えいで API キーが使われない。
- 引き受けるコスト：
  - 端末を替えた正当な利用者も 72 時間出金できない。画面で理由と終わりの時刻を示す。
  - 回復に eKYC の料金がかかる。マイナンバーカードを持たない人の回復は、CS の手順（人の確かめ）に回る。
  - API の利用者は Ed25519 の署名を実装する必要がある（例の実装を文書に置く）。
  - ADR-0008 の「パスワードの再設定」はこの決定の契機（TOTP の再設定、回復）に読み替える。

## Confirmation

- DT-KYC-003（重要な操作 × 直近の確かめ → 受けるか、待ちの終わり）の表駆動のテスト。
- PROP-KYC-002（任意の操作の列で、待ちの間の出金の受け付け 0）。PROP-KYC-006（API キーの要求が出金・宛先・キーの管理に届く経路 0）。
- E2E：パスキーの追加の後、出金が 72 時間拒まれ、時刻を進めて受ける。
- 外部のペンテスト（E16）の範囲に、回復とメールの変更の経路を入れる。
