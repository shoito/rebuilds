# ADR-0012: エンジンの入出力を固定の符号化にし、時刻を Tick で進める

## Context

エンジンの決定性（NFR-003）は、同じ入力のバイトから同じ出力のバイトが出ることで確かめる（[ADR-0002](0002-sequencer-and-event-journal.md)）。そのためには次を決める必要がある。

- 入力と出力の記録の形。要約（ハッシュ）を計算する対象のバイトが、言語・ライブラリ・ビルドで変わってはいけない。
- 時刻の進め方。エンジンは sequencer が付けた `ts` だけを時刻として使う（AGENTS.md）。しかし、取り消しだけの時間の終わり、参照の価格の古さ（[ADR-0003](0003-matching-rules-and-self-trade-prevention.md)）は、入力の来ない静かな板でも進まなければならない。
- 記録の形を変える時の扱い。再生の道具は、古い形の記録も読めなければならない。

## Options

符号化：

1. **自前の固定の配置の二進の符号化（`engine-proto`。整数は固定の幅の little-endian、列は長さの接頭辞、項目の順は型の定義の順）**
2. Protocol Buffers
3. JSON（serde）

静かな板の時刻：

- a. **sequencer が板ごとに 1 秒ごとに `Tick` の入力を入れる**
- b. `engine-host` が壁の時計で時間切れを判定し、入力を作る
- c. 時間で進む遷移は、次の入力が来たときに遅れて行う

## Decision

1 と a を採用する。

- `engine-proto` に入力と出力の型を Rust で定義し、符号化と復号を手で書く（生成しない）。各記録の先頭に、形のバージョン（`u16`）と型の番号（`u16`）を置く。
- 同じ値は 1 通りのバイトにしかならない（任意の項目、欠けた項目の既定、並びの自由を持たない）。復号は、余ったバイトと未知の型の番号を誤りにする。
- TypeScript の側（`order-gateway`、`ledger-poster`、`md-publisher`）は、同じ定義から作る読み書きの関数を使い、Rust と同じ試験のベクトル（バイト列と値の組）を通す。
- 形を変えるときはバージョンを上げる。再生の道具と読み手が新旧の両方を読めるようにしてから、書き手を上げる（[runbooks/README.md](../runbooks/README.md) の 3 節）。
- sequencer は、板ごとに、自分の時計の 1 秒の境界ごとに `Tick`（中身なし、`seq`・`ts`・`epoch` だけ）を入れる。他の入力が続く間も入れ、時間の進みを 1 秒の粒度で揃える。
- 時間で進む振る舞いは、`ts` が条件を満たした最初の入力（`Tick` を含む）の処理の前に起こす（[matching-engine.md](../architecture/matching-engine.md) の 4.6 節）。

### 他の案を選ばなかった理由

- **2**：同じ値に複数のバイト列がありうる（項目の順、既定の値の省略、未知の項目）。要約の対象には、別に正規の形を決め直すことになる。
- **3**：数値の表し方と空白と項目の順がライブラリで変わる。大きな整数（wei）の扱いも分かれる。大きさと速さも不利。
- **b**：エンジンの外の壁の時計が状態を変え、再生で同じ時刻に同じ遷移が起きる保証が sequencer の外に出る。
- **c**：板が静かなとき、取り消しだけの時間が終わらない。参照の価格の古さが判定できない。

## Consequences

- 良くなること：
  - 要約の対象のバイトが定義から 1 つに決まり、本番・写し・再生・TypeScript の読み手で同じになる。
  - 時間で進む遷移も記録の中にあり、再生で同じ点で起きる。
- 引き受けるコスト：
  - 符号化を手で書き、試験のベクトルを 2 つの言語で保つ。
  - `Tick` の分だけ記録が増える（板ごとに 1 日 86,400 件）。
  - 時間の粒度は 1 秒で、それより細かい期限は持てない（MVP の注文の種類には要らない）。

## Confirmation

- 試験のベクトル：型ごとに値とバイト列の組を持ち、Rust と TypeScript の両方で符号化と復号が一致する。
- 性質：任意の値で `decode(encode(v)) == v`。任意のバイト列で、復号が成功したら `encode(decode(b)) == b`。
- 性質：静かな板（`Tick` だけ）でも、`Resume` から取り消しだけの時間の後に `trading` になる（DT-ME-1）。
