# Airbnb

ホストが住まいや部屋を貸し、ゲストが泊まる世界の宿泊のマーケットプレイスを、「場所を伏せたリスティングと多言語の内容」「物件の現地の日付で持つ泊ごとの空室と、外部のカレンダーとの同期」「地図と地名と日付の範囲で絞る検索」「料金・手数料・税・通貨の見積もり」「同じ夜を二度売らない予約と仮押さえ」「チェックインまで預かり、チェックインの後にホストへ送る台帳と送金」「予約の前の連絡先の絞り込み、同時に公開するレビュー、本人確認と安全の T&S」「住宅宿泊事業法の届出番号・180 泊の上限・宿泊者名簿」として作り直す設計。日本を最初の市場にし、海外からのゲストを受ける。

主な論点：

1. リスティング：物件の種類、設備、写真、ハウスルール、位置の秘匿（予約までずらした位置）、多言語の内容と翻訳
2. 空室とカレンダー：泊ごとの空室、最短と最長の泊数、チェックイン・アウトの曜日、予約の締め切り、予約の間の準備の日、ブロック、物件のタイムゾーン、他の掲載先との iCal の取り込みと書き出し
3. 検索：地図の範囲と地名（日本語と外国語の地名）、日付の範囲の空室での絞り込み（中心の難しさ）、変動する料金での価格の絞り込み、順位付け、日付を決めない検索
4. 料金：泊ごとの料金、週末と季節の規則、長期の割引、清掃料などの料金、税（宿泊税、消費税、入湯税）、サービス料、複数の通貨の表示と支払い、料金の提案（ML の境界）
5. 予約：即時予約と予約のリクエスト、仮押さえと二重の予約の防止（本システムと外部のカレンダーをまたぐ）、オーソリと売上の確定の時期、キャンセルポリシーと返金の計算、日程の変更、予約の一回性
6. 決済と送金：ゲストの通貨での支払い、チェックインの後のホストへの送金（国内の振込と国際送金、為替）、台帳、税の預かりと納付、保証金と損害の請求
7. メッセージ：ゲストとホストのメッセージ、予約の前の連絡先の絞り込み、通信の秘密
8. レビュー：両者が出すか期限が来るまで隠し、同時に公開するレビューと、レビューの期間
9. T&S：ホストとゲストの本人確認、偽のリスティング・決済の不正・乗っ取り、パーティーの防止、安全の事故と 24 時間の支援、差別の禁止
10. 日本の法令（住宅宿泊事業法、旅館業法、宿泊者名簿と旅券の確認、宿泊税、個人情報保護法、特定商取引法、資金決済法、越境のデータ）。法務の確認待ち
11. ホストの道具：複数のリスティングの管理、共同ホスト、宿泊の管理のシステム（PMS）向けの API
