# ADR-0051: 保証金は MVP で持たない。MVP の後に出すときの形を、チェックインの 24 時間前のオーソリと、チェックアウトの 7 日後か請求の決着での取り消しに決め、オーソリの有効の期間が滞在 + 8 日より短い支払いの方法には保証金を求めない。出すには法務の L5・L12 の結論と提供者の能力の確かめが要る

## Context

- 保証金の預かりは MVP の後（intent の「MVP の後」）。理由は、オーソリの期限（数日）と予約から滞在までの長さが合わないこと、法務の L12。
- 後で出すときに、予約・決済・台帳の形を作り直さないよう、形の見通しを先に決めたい。
- オーソリの有効の期間は提供者とブランドで違う（**未検証**）。

## Options

1. **チェックインの 24 時間前にオーソリ、チェックアウトの 7 日後か請求の決着で取り消し**
2. 予約の時に請求し、チェックアウトの後に返す
3. 持たない（損害の請求だけ）

## Decision

MVP は 3。MVP の後に出す形は 1 にする。詳細は [deposits-and-claims.md](../architecture/deposits-and-claims.md) の 11 節。

- 予約の長さに依らず、オーソリはチェックインの直前だけ取る。オーソリの失敗は予約を取り消さず、支払いの方法の更新を求める。
- オーソリの有効の期間（提供者の能力の表の `authorization_validity`）が滞在 + 8 日より短い支払いの方法には保証金を求めない。
- 請求が認められたら、オーソリから確定する（損害の請求の行 13 の前の分岐）。
- 出す条件：法務の L5（預かりの性質）・L12、提供者の能力の確かめ。

### 他の案を選ばなかった理由

- **2**：ゲストのお金を長く預かり（L5）、返金の手数料と為替が増える。

## Consequences

- 良くなること：
  - MVP の流れを変えずに、後で保証金を足せる。
- 引き受けるコスト：
  - オーソリの期間の短い支払いの方法では、保証金を使えない。

## Confirmation

- 出す時の spec で、オーソリの期限と取り消しの時刻を仮想の時計の試験で確かめる。
