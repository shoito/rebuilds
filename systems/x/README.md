# X

公開型のマイクロブログの SNS を、「フォローした人の投稿が数秒で届くホームのタイムライン」と「日本語の投稿の流れから、見るべきものを選んで並べる推薦」として作り直す設計。まず日本の利用者を対象にする。

主な論点：

- ホームのタイムラインの fan-out（プッシュとプルの組み合わせ、フォロワーの多い利用者の問題）
- 大規模なフォローの関係
- 投稿の書き込みの経路と、時刻の順に並ぶ ID
- 「おすすめ」のランキング（候補の取り出し、ランキング、ML の境界）
- いいね・リポスト・表示の数のカウンター
- 日本語の全文検索とトレンド
- 通知、メディアの投稿と配信、DM
- トラスト＆セーフティ（モデレーション、スパムとボットの防御、通報、情報流通プラットフォーム対処法と発信者情報の開示）
- 公開 API とレート制限
