# ADR-0056: 大阪にウォームスタンバイを持ち、人の判断でワークフローで切り替える。大阪は生成器の番号 512〜1023 だけを使い、送った outbox の行を 1 時間残して切り替えの後に送り直す。写しは空から作り直し、合わせに要る `ar:` を入口を開く前に作る

## Context

- NFR-005：リージョンの障害で RPO 1 分・RTO 1 時間。写し（タイムライン・カウンター）は作り直す。
- `tid` の生成器の番号は、東京 0〜511、大阪 512〜1023（[ADR-0002](0002-post-ids-and-ordering.md)）。
- Aurora は Global Database で大阪へ複製される。Kinesis・SQS・Valkey はリージョンをまたいで複製されない。
- ADR-0005 は、Relay が送れた outbox の行を消すとした。送った直後に東京が落ちると、Kinesis の中の出来事は大阪の消費者に届かず、fan-out・通知・索引の後始末が欠ける。
- 写しが空になると、全員の読み出しが作り直しになり Aurora に集中する（[architecture/README.md](../architecture/README.md) の 6 節）。合わせに使う `ar:` がないと、フォロワーの多い作者の投稿がホームから消える（[ADR-0015](0015-fanout-pipeline-and-burst-control.md)）。

## Options

1. **ウォームスタンバイ。送った outbox の行を 1 時間残し、大阪の Relay が直近 15 分を送り直す。写しは作り直し、`ar:` を先に作る**
2. パイロットライト（大阪は DB の複製だけで、サービスは切り替えの時に作る）
3. 東京と大阪の両方で書き込みを受ける（アクティブ・アクティブ）

## Decision

1 を採用する。詳細は [infrastructure.md](../architecture/infrastructure.md) の 7 節。

- 手順：東京の書き込みを止める（届けば）→ 大阪の Aurora を昇格 → 大阪のサービスを広げる → 合わせに要る作者（フォロワー 1,000 人以上と `fanout:pull_any`）の `ar:` を Aurora から作る → 大阪の Relay が送り直す → 作り直しの上限を下げる → 入口を大阪へ → 書き込みを開く → 検索の索引をスナップショットから戻す（検索の RTO 4 時間）。
- 大阪のタスクは、待機の間も切り替えの後も、生成器の番号 512〜1023 だけを借りる。失った範囲の貸し出しの行があっても重ならない。
- outbox の行は送った後も `sent_at` を立てて 1 時間残し、1 時間ごとの区画を落とす。ADR-0005 の「送れたら行を消す」を、この点で変える。消費者は冪等なので、送り直しの重複はよい。
- `rds.global_db_rpo` は設定しない。`AuroraGlobalDBRPOLag` が 10 秒を超えたら呼び出す。
- 東京へ戻すのは、別の計画作業の switchover（RPO 0）。
- 2 を採らない理由：サービスの起動と広げに時間がかかり、RTO 1 時間を守りにくい。DR の訓練の頻度も下がる。
- 3 を採らない理由：投稿・フォロー・いいねの書き込みの衝突の解き方と、`tid` 以外の一意の制約（ハンドル、連絡先）の扱いが要る。S3 の構成で別に検討する。

## Consequences

- 良くなること：
  - 大阪で振った ID が東京の ID と重ならない。
  - 送った直後の出来事の欠けを、送り直しで埋められる。
  - フォロワーの多い作者の投稿が、切り替えの直後もホームに出る。
- 引き受けるコスト：
  - outbox の 1 時間ぶんの行（S1 で 11〜20 GB）を Aurora に持つ。
  - 切り替えの後、利用者の作り直しの間、ホームが短い（`partial`）。
  - 失った範囲（RPO の窓）の確定は失う。
  - 大阪の待機の費用。

## Confirmation

- 性質ベーステスト：PROP-INFRA-002（東京の最後の k 件を失い、送り直しの窓を重ねても、大阪の消費者の結果は 1 回ずつ当てた結果と同じ）。
- DR の訓練（staging 四半期）：[quality.md](../quality.md) の 2.4 節の基準に、`ar:` の先の作成、送り直しの後の照合の差、大阪の生成器の番号を足す。
- Terraform の検査：大阪の生成器の範囲の変数が 512〜1023。
