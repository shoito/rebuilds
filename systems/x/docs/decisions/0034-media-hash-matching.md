# ADR-0034: 有害なメディアのハッシュの照合は差し替えられる口の後ろに置き、公開のメディアは照合を通るまで公開しない。自前で措置したメディアの PDQ の一覧も持つ。DM のメディアは L3 の確認まで照合しない

詳細は [media.md](../architecture/media.md) の 9 節、[trust-and-safety.md](../architecture/trust-and-safety.md) の 9 節。

## Context

- 既知の児童の性的搾取の画像などの違法なメディアは、外部の団体・事業者が持つハッシュの一覧で照合するのが業界の通例である。提供者はまだ決まっていない（[architecture/README.md](../architecture/README.md) の 6 節の持ち越し）。候補（Microsoft の PhotoDNA、Thorn の Safer など）の日本での提供の条件と、送る値は**未検証**。
- 提供者に何を送るか（ハッシュだけか、画像か）で、外国にある第三者への提供（L4）の扱いが変わる。
- 一度措置したメディアの再投稿（少し変えたもの）を止めたい。
- DM のメディアの照合は、通信の秘密（L3）の確認待ち。
- 試験に本物の有害なメディアを使えない（[AGENTS.md](../../AGENTS.md)）。

## Options

1. **`HashMatcher` の口の後ろに、外部の提供者と自前の PDQ の一覧を置く。公開のメディアは照合を通るまで公開しない（閉じる側）**
2. 照合を非同期にし、公開の後で一致したら措置する（開く側）
3. 提供者が決まるまで照合を作らない

## Decision

1 を採用する。

- 口は `match({ sha256, pdq, frames }) → none | known_illegal | known_policy`。外部の提供者と自前の一覧を順に呼ぶ。提供者の差し替えは実装の追加だけで済む。
- 自前の一覧：措置で `remove` にしたメディアの PDQ を `media_hash_blocklist` に持ち、ハミング距離 31 以下で一致（初期値。誤一致の率を測って決める）。PDQ は第三者の公開のアルゴリズムで、本家の実装ではない。
- 公開の投稿・アイコン・ヘッダーのメディアは、`none` が返るまで `processing` に進めない。提供者の障害の間は処理が止まる（閉じる側）。10 分で `failed` にし、もう一度上げるよう促す。
- `known_illegal` は `blocked`、隔離、T&S の P0 の案件。外部への届け出は L7 の確認待ち。`known_policy` は `blocked` と P2 の案件。投稿者には一致の種類を示さない。
- DM のメディアは照合しない。L3 の確認の後に、この ADR を見直す。
- 試験は提供者の試験用のハッシュと合成の画像で行う。
- 2 を採らない理由：一致するまでの間、違法なメディアが CDN と端末に載る。一度配ったものは取り戻せない。
- 3 を採らない理由：MVP の公開に、既知の違法なメディアの対策がないことになる。口だけ先に作れば、提供者が決まった時に差し込める。自前の一覧は提供者なしで効く。

## Consequences

- 良くなること：
  - 既知の違法なメディアが一度も公開されない。
  - 提供者を後で決め、替えられる。
  - 措置したメディアの再投稿を止められる。
- 引き受けるコスト：
  - 提供者の障害で、公開のメディアの投稿が止まる（可用性より安全を取る）。障害の手順と、提供者の SLA の確認が要る。
  - 照合の時間が画像の処理の予算（p95 3 秒のうち 800ms）を使う。
  - DM のメディアは、L3 の確認まで照合の外に残る。

## Confirmation

- 性質ベーステスト：PROP-MEDIA-001（照合が `none` でない公開のメディアは `ready` にならない）。
- 結合テスト：提供者の模擬（試験用のハッシュ）で `known_illegal`・`known_policy`・障害・時間切れの各場合。
- lint：DM の `purpose` のメディアの処理から `HashMatcher` を呼ぶ道を、L3 のフラグ（`release.dm_media_matching`）の外で作らない。
- 本番：照合の待ちの件数と時間、一致の件数、自前の一覧の誤一致の申し立ての件数。
