# ADR-0009: 削除と措置は行を消さずに状態と `state_version` を変える。投稿の状態の写しは版の新しいものだけを書き、寿命を 45 秒にして、出来事が止まっても 60 秒の中で正本に戻る

## Context

`visible()` は、読み出しのたびに投稿の状態（削除、措置、作者の鍵の状態）を要る（[ADR-0004](0004-single-tenant-and-visibility.md)）。タイムラインの 1 ページで数十〜数百件を判定するので、状態は Valkey の写しから読む。

NFR-009 は、削除・措置から全経路で見えなくなるまで p99 60 秒を求める。写しが古いままだと、削除した投稿が出続ける。写しの更新が出来事の経路（Relay → Kinesis → 消費者）だけに頼ると、その経路が止まったときに 60 秒を守れない。Aurora の reader は writer より遅れるので、写しのない投稿を reader から読み込むと、削除の前の状態で写しを上書きしうる。

措置は取り消せる形で持ち、物理の削除は保持の期間の後のジョブだけが行う（AGENTS.md）。開示の請求のための保全（法務の L2）もある。

## Options

削除の持ち方：

1. **行を残し、状態（`state`・`mod_flags`）と `state_version` を変える。物理の削除は保持の後のジョブ**
2. 削除で行を消す（別の表に移す）

写しの更新：

- a. **版つきの写し。書き込みは版が今以上のときだけ。削除の確定の直後に新しい状態を書き、出来事の消費者が補い、寿命 45 秒で正本に戻る**
- b. 削除で写しを消す（DEL）。出来事の消費者も消す
- c. 写しを持たず、毎回 Aurora の reader を引く

## Decision

1 と a を採用する。詳細は [posts-and-ids.md](../architecture/posts-and-ids.md) の 5.4・6・7 節。

- `posts.state` は `active`・`deleted`・`purged`。措置の要約は `mod_flags`（正本は `moderation_actions`）。状態が変わるたびに `state_version` を上げる。
- `ps:{post_id}` は Valkey Functions の `ps_put` で書き、版が今以上のときだけ書く。寿命は 45 秒。
- 削除・措置の確定の直後に、書き込みのサービスが新しい状態を書く。失敗したら、`posts`・`moderation` の流れの消費者が書く。どちらも止まっても、寿命で切れて正本から読み直す。
- 作者の鍵の状態は `as:{user_id}` に同じ規則で持ち、`PostState` を組み立てるときに合わせる。
- 2 を採らない理由：措置は取り消せる必要があり、会話の中の「削除された投稿」の枠と、子の返信の親を保つ必要がある。保全（L2）とも合わない。
- b を採らない理由：消した直後に、遅れた reader から削除の前の状態が読み込まれ、写しに戻りうる。
- c を採らない理由：読み出しのピーク（S1 で 1 万件/秒 × 1 ページ数十件）を reader で受けることになり、NFR-003 を守れない。

## Consequences

- 良くなること：
  - 出来事の経路が全部止まっても、写しの古さが 45 秒で上限になる。
  - 遅れた reader が新しい状態を壊さない。
- 引き受けるコスト：
  - 人気の投稿でも 45 秒ごとに正本を引く。S1 の想定で、写しを引く件数の 1% 未満。
  - `state_version` を、状態を変える全ての経路（作者の削除、措置、取り消し、保持のジョブ）で上げる規則を守る必要がある。
  - 写しがなく reader が遅れている瞬間は、削除の前の状態が reader の遅れの分だけ見えうる（NFR-009 の 60 秒の中）。

## Confirmation

- 性質ベーステスト：PROP-POST-003（版が減らない。最後の出来事から 45 秒で正本と一致）。
- 結合テスト：削除の直後の `ps_put` を失敗させ、Relay を止めても、60 秒以内に全経路で見えない。
- lint：`posts.state`・`mod_flags` を変える SQL が `state_version` を上げないものを、マイグレーションと問い合わせの検査で拒否する。`ps:` への書き込みを `ps_put` 以外で行うことを禁止する。
- 本番：見える範囲の抜き取りの監査で、写しが正本より古かった件数を数える。
