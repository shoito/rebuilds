# Intent: X を AI エージェント主体で再構築する

- Author: shoito
- Status: draft
- Date: 2026-10-04

## Problem

公開型のマイクロブログの SNS は、誰でも短い文を投稿し、誰でもそれを読める。日本では、ニュースの速報、災害の情報、趣味の集まり、企業の告知、テレビの実況が、同じ流れの上で起きる。本家の日本の利用者は、月間 6,800 万人とされる（本家の日本法人の代表の講演を伝える二次資料。**未検証**）。

この種のサービスを作り直すとき、難しいのは画面ではなく、次の 4 つである。

- **届ける**：1 件の投稿を、数十人から数千万人のフォロワーのホームへ、数秒で届ける。フォロワーの多い利用者の投稿で、書き込みの量が爆発する（いわゆるセレブリティの問題）。
- **選ぶ**：毎日の膨大な投稿から、1 人ひとりに見る価値のあるものを選んで並べる。本家は、1 回の「おすすめ」のために約 1,500 件の候補を集め、約 4,800 万のパラメーターのニューラルネットワークで並べると説明している（2023 年の本家のブログを引用する第三者の記事で確かめた。本家のブログには到達できず、一次資料は**未検証**）。
- **数える**：いいね・リポスト・表示の数を、毎秒何万件の更新の中で、速く、おおむね正しく見せる。
- **守る**：スパムとボット、誹謗中傷、違法な情報への対応を、日本の法令（情報流通プラットフォーム対処法、発信者情報の開示）の手続きに沿って、期限の中で行う。

この 4 つを中心に、小さなチームと AI エージェントでどこまで作り直せるかを確かめる。

## Proposed outcome

日本の利用者が、待たずに投稿し、フォローした人の投稿を数秒で受け取り、おすすめで新しい人と話題に出会える SNS を作り直す。次の 4 つの価値を満たす。

1. **すぐ届く**：フォローした人の投稿が、ホーム（フォロー中）に p95 5 秒以内に出る（NFR-002）。フォロワーが 1,000 万人の利用者の投稿でも同じ。
2. **速く読める**：ホームの最初のページを p99 300ms で返す（NFR-003）。
3. **見てはいけないものを見せない**：ブロック・鍵アカウント・削除・法的な措置の投稿が、どの経路でも見えてはいけない人に出ない（NFR-009）。
4. **期限を守る**：法令の削除の申出に、期限の中で判断して通知する（NFR-010）。

### MVP（S1）に含める

- **アカウントとプロフィール**：電話番号かメールアドレスでの登録、パスキー、Google・Apple でのログイン。ハンドル（`@name`）、表示名、自己紹介、アイコン、ヘッダーの画像。鍵アカウント（承認したフォロワーだけが読める）
- **投稿**：本文（重み付きで 280。日本語・中国語・韓国語の文字は 2 と数え、全角で 140 文字。URL は短縮して 23 と数える。本家と同じ）、画像（4 枚まで）・GIF・動画、返信とスレッド、引用、リポスト、削除、返信できる人の制限
- **フォロー**：フォロー・解除、鍵アカウントへのフォローの申請と承認、ブロック、ミュート（アカウントと語）、フォロー中・フォロワーの一覧
- **タイムライン**：ホームの「フォロー中」（時刻の順）と「おすすめ」（ランキング）、プロフィールの投稿の一覧、返信の会話の表示
- **エンゲージメント**：いいね、リポスト、ブックマーク、表示の数
- **検索とトレンド**：投稿・利用者の全文検索（日本語の部分一致）、ハッシュタグ、日本のトレンド
- **通知**：返信、メンション、いいね、リポスト、フォロー、引用。アプリの中の一覧と、プッシュ通知（APNs・FCM）、メール
- **DM**：1 対 1 とグループ（50 人まで）、既読、画像、メッセージの申請（フォローしていない人から）
- **トラスト＆セーフティ**：通報、モデレーションの作業の画面、規約の違反の措置（削除、表示の制限、凍結、異議の申立て）、スパムとボットの検出、情報流通プラットフォーム対処法の削除の申出の窓口、発信者情報の開示の請求への対応、センシティブなメディアの設定
- **公開 API**：投稿・利用者・タイムライン・検索・DM の読み書き、OAuth 2.0（PKCE）、アプリと利用者ごとのレート制限、使った量の計量
- **クライアント**：Web（レスポンシブ、PWA）と、iOS・Android のアプリ

### 守るべき振る舞い

- 鍵アカウントの投稿は、承認したフォロワーと本人以外に、タイムライン・検索・通知・API・埋め込み・メディアの URL のどの経路でも見えない。
- ブロックした人の投稿は、ブロックした人に見えない。ブロックされた人は、ブロックした人の投稿を読めず、フォロー・返信・DM ができない。
- 削除した投稿と、法的な措置・規約の措置で非表示にした投稿は、措置から 60 秒以内に全経路で見えなくなる（NFR-009）。
- 確定を返した投稿・DM・フォローは失われない。
- いいね・リポストの数は、関係の正本から数え直した値に収束する。表示の数は概算だが、減らない。
- DM の中身は、当事者と、法令に基づく手続きを経た場合を除き、誰にも読まれない。
- 措置を受けた利用者には、措置と根拠と異議の申立ての方法が示される。

### 成功の基準

| # | 基準 | 目標 | 測り方 |
| --- | --- | --- | --- |
| K1 | 届く速さ | 投稿からフォロワーのホーム（フォロー中）に出るまで p95 5 秒、p99 30 秒（NFR-002）。フォロワー 1,000 万人の利用者でも同じ | 合成監視（監視用のフォロワーの組）と、fan-out の遅延の計測 |
| K2 | 読む速さ | ホーム（フォロー中）の最初のページ p99 300ms、おすすめ p99 800ms（NFR-003） | サーバーの計測と RUM |
| K3 | 見える範囲の分離 | 見てはいけない投稿・DM が見えた事象 0 件（NFR-009） | 性質ベーステスト、本番の抜き取りの監査 |
| K4 | 数の正しさ | いいね・リポストの数の写しと正本の差 0（照合の後）、表示までの遅れ p95 5 秒（NFR-006） | 照合のジョブ |
| K5 | 可用性 | タイムラインの読み出し月間 99.95%、投稿の書き込み・DM・公開 API 月間 99.9%（NFR-004） | 合成監視と 5xx の割合 |
| K6 | 法令の期限 | 削除の申出への判断と通知を期限の中で行った割合 100%（NFR-010） | T&S の案件の記録 |
| K7 | スパムの抑止 | 抜き取りの人の評価で、ホームに出たスパムの割合 0.5% 以下（NFR-011） | 週ごとの抜き取りの評価 |
| K8 | おすすめの価値 | おすすめのタイムラインの 1 回の訪問の中の、いいね・返信・リポスト・プロフィールへの移動の率が、フォロー中の時刻の順の並びより 20% 以上高い | A/B の試験（同じ期間、同じ利用者の集団） |

## Affected users and systems

- **一般の利用者**（主な利用者）：日本の、主にスマートフォンで使う人。読むだけの人が多く、投稿する人は一部である。日本語の入力・検索・表示を前提にする。
- **フォロワーの多い利用者**：芸能人、報道機関、自治体、企業の公式のアカウント。1 件の投稿が数百万人に届く。災害の時の自治体の投稿は、遅れが許されない。
- **モデレーター・T&S の担当者**：通報と申出を判断する社内（と委託先）の人。
- **開発者**：公開 API を使うアプリ・ボット・研究者。
- **外部のシステム**：APNs・FCM、メールの送信事業者、SMS の送信事業者、有害なメディアのハッシュの照合の提供者、裁判所・捜査機関（開示の命令・照会）、総務省（情報流通プラットフォーム対処法の報告）。

## Constraints

- **タイムライン・推薦・カウンター・検索の核を自前で設計する。** 本家が公開したアルゴリズムのコード（`twitter/the-algorithm`、`xai-org/x-algorithm`）、`twitter-text`、本家の ID の生成器を使わない（[リポジトリ共通の ADR-0007](../../../docs/decisions/0007-no-reuse-of-original-implementation.md)、[ADR-0001](decisions/0001-platform-and-stack.md)）。
- 実行基盤と技術は、rebuilds の他の題材の決定（AWS 東京・大阪、TypeScript、Aurora PostgreSQL、Valkey、S3、SQS・SNS、ECS Fargate、Terraform、OpenTelemetry、AppConfig）を引き継ぐ。外れるもの（64 ビットの ID、Kinesis Data Streams、学習の Python）は ADR に理由を書く（[ADR-0001](decisions/0001-platform-and-stack.md)）。
- 本家の名前は識別子に使わない。ドメインは `<brand>.<domain>`、短縮 URL は `<brand>.<short-tld>` の形で書く（[リポジトリ共通の ADR-0006](../../../docs/decisions/0006-brand-neutral-identifiers.md)）。本家の API・SDK とそのまま互換にすることは目標にしない。
- データは日本（東京、DR は大阪）に置く。
- 日本の法令（情報流通プラットフォーム対処法、電気通信事業法、個人情報保護法、青少年インターネット環境整備法、著作権法、特定電子メール法）への対応は、法務の確認を前提に設計する。結論は出さない（下の「法務の確認待ち」）。
- 規模は段階的に広げる（[architecture/](architecture/README.md) の「規模の段階」）。

## Non-goals

| 機能 | 理由 |
| --- | --- |
| 本家の API・SDK・埋め込みのコードとの完全な互換 | 形は寄せるが、名前と識別子は独自にする（リポジトリ共通の ADR-0006） |
| 分散型の SNS のプロトコル（ActivityPub、AT Protocol）での他のサーバーとの連合 | 中央の 1 つのサービスとして設計する。連合はモデレーションと fan-out の前提を変える |
| AI のチャットのアシスタント（本家の Grok に相当）、画像の生成 | SNS の核の論点ではない |
| 決済・送金（本家が進める X Money に相当） | 金融の規制の扱いが別になる |
| 本家の推薦の結果の再現 | 本家と同じ並びを出すことは目標にしない。K8 の価値で評価する |

### 選定・計測で決めるもの（法務以外）

- fan-out の閾値（プッシュとプルを分けるフォロワーの数）：S1 の既定は 1 万。E5 の PoC で、書き込みの量と読み出しの遅れの釣り合いを測って決める（[ADR-0003](decisions/0003-timeline-fanout-hybrid.md)）。
- 閲覧の数の取り込みの費用と誤差：E6 の前の `view-count-poc` で、Kinesis Data Streams の費用と、投稿ごとの数の写し（Valkey のハッシュ `pc:{post_id}` の `view`）とデータレイクの集計の差を測る。方式は決めた（束をセッションの鍵で流し、数えすぎない側に倒す。[ADR-0024](decisions/0024-view-counts-ingest-and-approximation.md)）。
- 日本語の全文検索：OpenSearch で、一致の判定は N-gram、関連度は kuromoji に決めた（[ADR-0025](decisions/0025-search-engine-and-japanese-analysis.md)）。E9 の前の `search-poc` で、索引の大きさと p99、Sudachi との比較を測る。
- S2 で投稿の表を分ける鍵：投稿の ID のハッシュに決めた。作者・会話の一覧は別の索引の表にする（[ADR-0010](decisions/0010-post-table-partitioning-s2.md)）。S1 の計測で作者の一覧の読み出しが多ければ見直す。
- スパムの判定の部品：S1 は自前の規則と線形の危険の点で始め、第三者の分類のサービスは買わない（[ADR-0040](decisions/0040-spam-and-bot-defense.md)）。有害なメディアのハッシュの照合の提供者は、口（`HashMatcher`）の後ろに置いて E11 の `media-hash-matching` で選ぶ（[ADR-0034](decisions/0034-media-hash-matching.md)）。
- 本家の現在の投稿の上限（1 日の投稿の数）：本家の文書は、1 日 2,400 件（30 分ごとの区切りあり）、DM 1 日 500 件、フォロー 1 日 400 件と書いている（[About X limits](https://help.x.com/en/rules-and-policies/x-limits)。検索結果の抜粋で確認し、本文は 403 で**未検証**。2026-10-04 に取得を再び試みて 403）。2026 年 5 月に認証のないアカウントの投稿を 1 日 50 件・返信 200 件に絞ったと報じられている（第三者の報道。**未検証**）。本システムの値は投稿 1 日 1,000 件（電話の確認のないアカウントは 50 件）に決めた（[api-and-rate-limits.md](architecture/api-and-rate-limits.md) の 5.3 節）。
