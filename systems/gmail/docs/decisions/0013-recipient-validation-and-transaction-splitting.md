# ADR-0013: 宛先は RCPT の時点でキャッシュつきの address_index で確かめ、ない・停止・容量の超過をその場で返す。知らない宛先の連続は接続ごとに遅らせて切り、IP の評判に数える。宛先の方針の組がトランザクションの中で食い違うときだけ、後の宛先に 452 4.5.3 を返してトランザクションを分けさせる

詳細は [inbound-smtp.md](../architecture/inbound-smtp.md) の 8 節。

## Context

- [ADR-0002](0002-accept-then-filter.md) は、ない宛先を 550 5.1.1、停止を 550 5.2.1、容量の超過を 452 4.2.2 で返すと決めた。受け付けた後に宛先がないと分かると、DSN を作ることになり、偽の差出人への後方散乱になる。
- 宛先を RCPT の時点で答えると、攻撃者がアドレスの有無を探れる（ディレクトリの収穫）。SMTP では避けられないが、速さを抑えられる。
- 宛先の解決は RLS の外の `address_index` を引く（[ADR-0007](0007-tenancy-accounts-orgs-and-rls.md) の X1）。ピークの RCPT は数千/秒で、directory に毎回当てたくない。
- SMTP の時点の判定（DMARC の `p=reject` で拒むかなど）を組織ごとに変えたい要望がある。DATA の後の応答は 1 つのトランザクションで 1 つで、宛先ごとに変えられない（[ADR-0002](0002-accept-then-filter.md)）。

## Options

宛先の確認：

1. **RCPT の時点でキャッシュつきで確かめ、探りを遅らせて切る**
2. すべての宛先を受け、後で配れない宛先に DSN を返す

方針の違う宛先：

- a. **方針の組が違うときだけ、後の宛先に 452 4.5.3 を返して分けさせる**
- b. 最も緩い方針で受け付け、受け付けた後に宛先ごとに迷惑メールの箱か隔離にする
- c. 方針を組織ごとに変えさせない

## Decision

1 と a を採用する。

- アドレスを正規化（ドメインは小文字と A-label、ローカル部は NFC と小文字、`+` の後ろを外す。点と大文字小文字はドメインの設定に従う）し、テナントの鍵の HMAC で `address_index` を引く。
- キャッシュは台の LRU（60 秒）と Valkey（あるもの 5 分、ないもの 60 秒）。directory の変更は outbox の通知で消す。
- directory に届かないとき、手元のキャッシュに当たらない宛先は 451 4.4.3 にする。恒久のエラーにしない。
- 1 つのセッションで「ない宛先」が 5 回を超えたら 1 秒ずつ遅らせ（最大 5 秒）、20 回で切り、IP に 24 時間の罰を足す。
- 宛先ごとの受信の速さ（宛先 × 範囲、宛先の合計）の上限で 452 4.2.1 を返す。
- テナントは `smtp_policy_class` を持ち、既定は全員で同じ `default`。最初に受けた宛先と違う組の宛先には 452 4.5.3 を返す（RFC 5321 の 4.5.3.1.10 節）。

### 他の案を選ばなかった理由

- **2**：配れない宛先への DSN が、偽の差出人への後方散乱になる（[ADR-0002](0002-accept-then-filter.md)）。
- **b**：`p=reject` を拒みたい組織のメールまで受け付けることになり、組織の選んだ方針が効かない。
- **c**：組織の要望（取引先の誤った DMARC の設定で、メールを失いたくない）に応えられない。

## Consequences

- 良くなること：
  - 配れない宛先を受け付けない。後方散乱を作らない。
  - 探りの速さを抑え、探る IP を評判で見分けられる。
  - 組織ごとの SMTP の時点の方針を、SMTP の範囲で正しく分けられる。
- 引き受けるコスト：
  - 宛先の有無は、SMTP の応答で分かってしまう（SMTP の性質）。
  - 方針の組が違うと、送り手の再試行の間だけ配送が遅れる。既定の組だけなら起きない。
  - 宛先のキャッシュの寿命の間（最大 5 分）、消したアドレスに配りうる。配送の時に `mailstore` がアカウントの状態をもう一度確かめる。

## Confirmation

- 性質ベーステスト：PROP-MX-006（1 つのトランザクションの宛先は同じ組で、100 を超えない）。
- 決定表：DT-MX-001 の RCPT の行を `smtp-peer-sim` で確かめる。
- 試験：directory の停止の注入で、知らない宛先に 550 を返さないこと。
- 監視：「ない宛先」の率と、探りの罰の数。
