# ADR-0033: ラベルの操作は 1 つの関数と決定表 DT-MBX で当てる。`SPAM`・`TRASH` を付けると他の所属は残して隠し、`INBOX` は外して「隠す前に受信箱にあった」印を残し、戻すときに印で戻す。スレッドへの操作はその時点のメッセージに当てる。ミュートは受信箱から外し、利用者だけに宛てたメッセージでだけ戻す。スヌーズは `SNOOZED`＋時刻で、時刻か新しい返信で起こす。ゴミ箱と迷惑メールの箱は 30 日で消す。ラベルの消去は背景で 1,000 通ずつ外す

詳細は [mailbox-model-labels-and-threads.md](../architecture/mailbox-model-labels-and-threads.md) の 4・5 節。

## Context

- [ADR-0004](0004-labels-as-primary-mailbox-model.md) は、`SPAM`・`TRASH` を他のラベルと排他にし、付いたメッセージを他の一覧から外し、所属は残して戻したときに元に戻すと決めた。一方で、`SPAM`・`TRASH` を付けると `INBOX` は外す。戻すときに `INBOX` を戻すかは決めていない。
- IMAP の UID は、見える所属になるたびに新しく振る（[ADR-0006](0006-sync-protocol-jmap-imap-and-modseq.md)）。隠すことを「所属を外す」と同じに扱うと、戻せない。
- ミュート・スヌーズ・ゴミ箱の期限・ラベルの消去は、JMAP・IMAP・フィルター・期限の掃除の多くの経路から来る。経路ごとに意味がずれると、同期の収束が崩れる。
- 本家のミュートの詳しい条件、スヌーズのスレッドへの新しい返信の扱いは、公式の資料で確かめられなかった（**未検証**）。

## Options

隠し方：

1. **所属の行に `hidden` を持ち、`INBOX` は外して印を残す**
2. 他の所属をすべて外し、戻すときは失う
3. `INBOX` も隠すだけにする（外さない）

スヌーズの新しい返信：

- a. **新しい返信でスレッドを起こす**
- b. 時刻まで起こさない

## Decision

1 と a を採用する。

- `apply_label_op` だけが所属を変え、決定表 DT-MBX（15 行）で当てる。
- `SPAM`・`TRASH` を付けるとき、`inbox_before_hide` に `INBOX` の有無を記録し、`INBOX` と `SNOOZED` を外し、他の所属を `hidden` にする。外すとき、所属を戻し、印が真なら `INBOX` を足す。
- スレッドへの操作は、操作の時点のスレッドのメッセージで `SPAM`・`TRASH` を持たないもの（ゴミ箱・迷惑メールの画面からはそれを持つもの）に当て、1 つの `modseq` にする。1 回 1,000 通まで。
- ミュートはスレッドの属性で、ミュートの時にスレッドをアーカイブし、以後のメッセージに `INBOX` を付けない。`To` に利用者だけがあるメッセージは例外として `INBOX` を付ける。
- スヌーズは `SNOOZED`＋`snooze_until`（1 分後〜1 年後）。時刻か、スレッドへの新しいメッセージで起こし、`INBOX` と `inboxAt` を付ける。
- ゴミ箱と迷惑メールの箱は `trash_at`・`spam_at` から 30 日で完全に削除する（アカウントごとの文脈で回す。[ADR-0007](0007-tenancy-accounts-orgs-and-rls.md) の X4）。
- ラベルの消去は、ラベルを `deleting` にしてすぐ見えなくし、所属を背景で 1,000 通ずつ外す。

### 他の案を選ばなかった理由

- **2**：誤ってゴミ箱に入れたメッセージを戻すと、ラベルが失われる。[ADR-0004](0004-labels-as-primary-mailbox-model.md) の「戻したときに元に戻る」に反する。
- **3**：迷惑メールの判定の後もメッセージが受信箱の件数に数えられ、IMAP の `INBOX` で隠し方が他の箱と違う形になる。
- **b**：返信を待っていたスレッドの返信が、利用者に見えないまま時刻まで隠れる。

## Consequences

- 良くなること：
  - どの経路の操作も同じ表で当たり、決定表で全行を試験できる。
  - ゴミ箱・迷惑メールから戻すと、ラベルと受信箱が元に戻る。
- 引き受けるコスト：
  - 隠した所属を IMAP では消えたものとして見せ、戻すと新しい UID になる（既存のアプリは再取得する）。
  - ミュートとスヌーズの条件が本家と違う可能性がある（**未検証**）。
