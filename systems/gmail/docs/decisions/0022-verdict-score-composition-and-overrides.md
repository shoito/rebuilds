# ADR-0022: 選別の各層は迷惑メールとフィッシングの 2 つの頭ごとに対数オッズの寄与を出し、和をシグモイドで確率にして閾値で判定する。やりとりのある相手は DMARC の pass のときだけ閾値を上げる。既知のマルウェアは点によらない。上書きの順は決定表で決め、既知のマルウェアと確かなフィッシングは利用者・組織の許可でも上書きしない

詳細は [spam-and-abuse-filtering.md](../architecture/spam-and-abuse-filtering.md) の 5・8 節。

## Context

- [ADR-0008](0008-spam-pipeline-boundary-and-secrecy.md) は、規則・評判・分類器・添付と URL の層を合わせて、判定と理由のコードを出すと決めた。合わせ方は決めていない。
- NFR-009 は、正規のメールの誤判定を 0.05% 以下、やりとりのある相手からは 0.005% 以下にすることを求める。やりとりのある相手のアドレスは、なりすましで騙られやすい。
- 迷惑メールとフィッシングは、誤りの重さが違う。フィッシングの見逃しは被害になり、迷惑メールの見逃しは迷惑で済む。
- 利用者の操作（連絡先、フィルター、迷惑メールではない）で判定を上書きできる。ただし既知のマルウェアの添付は、利用者の設定に関わらず開かせない（[intent.md](../intent.md)）。
- 層は部品の障害で欠けうる。欠けたときに迷惑メールに寄せると、正規のメールを落とす。

## Options

1. **頭ごとの対数オッズの和と閾値、決定表の上書き**
2. 1 つの学習したモデルに全部の層の出力を入れる（スタッキング）
3. 規則の点の足し算（迷惑メールの点、1 つの閾値）

## Decision

1 を採用する。

- 頭は `spam`・`phish`。`S = b + Σ w`、`p = σ(S)`。`b_spam = −3.0`、`b_phish = −5.0`。評判の寄与は −4〜+4、分類器の寄与（較正の後）は −6〜+6 に切る。
- 判定：`p_phish ≥ 0.80` で `spam_phish`、`p_spam ≥ 0.90` で `spam`、`p_phish` 0.50〜0.80 か `p_spam` 0.70〜0.90 で `inbox_warn`、それ以外は `inbox`。やりとりのある相手（DMARC の `pass` のときだけ）は `phish` 0.95・`spam` 0.99。
- `quarantine` は組織の方針の置き換え、`attachment_blocked` は重ねる印。
- 上書きの順（DT-FLT-001）：既知のマルウェア → 確かなフィッシング（`p_phish ≥ 0.98`）→ 組織の拒否 → 組織の許可（認証の `pass` のときだけ）→ 利用者の「迷惑メールにしない」→ 利用者の「迷惑メールにする」・ブロック → 組織の隔離の方針 → 閾値。
- 層が欠けたときは閾値を変えず、欠けた層を 0 として合わせる。2 つ以上欠けたら判定なしの `inbox` にして後から選び直す。
- 理由のコードは 1 通あたり最大 3 つ。規則の中身と点の値は利用者に見せない。
- 閾値は選別のバージョン（`filter_version`）としてモデルと一緒に出す。

### 他の案を選ばなかった理由

- **2**：層の 1 つが欠けたときの振る舞いが読めない。理由のコードを出しにくい。規則と評判の変更のたびに学習し直す。
- **3**：迷惑メールとフィッシングの誤りの重さを分けられない。評判と分類器の確率を、意味の揃った形で足せない。

## Consequences

- 良くなること：
  - 層ごとの寄与が足し算で読め、理由のコードと調べに使える。
  - フィッシングを迷惑メールより強く拾える。
  - 欠けた層で正規のメールを落とさない。
- 引き受けるコスト：
  - 寄与の値と事前と閾値を、評価の集まりと影で直し続ける。
  - 層の間の相関（評判と分類器が同じものを見る）で、寄与が二重に効く。評価の集まりの較正で抑える。

## Confirmation

- 決定表：DT-FLT-001（上書き）、DT-FLT-002（閾値）を表駆動テストで全行、選別の範囲の設定ごとに確かめる。
- 性質ベーステスト：PROP-FLT-001（欠けで厳しくならない）、PROP-FLT-002（既知のマルウェアの印）。
- 評価の集まり（[quality.md](../quality.md) の 2.2.1 節 H）：NFR-008・NFR-009 を上限で満たす。
