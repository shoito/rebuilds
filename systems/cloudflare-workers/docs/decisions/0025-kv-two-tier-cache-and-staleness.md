# ADR-0025: KV の読み込みはノードとリージョンの 2 段のキャッシュで返し、古さは正本から取った時刻で数える

詳細は [kv-store.md](../architecture/kv-store.md) の 6 節。

## Context

ADR-0005 と NFR-009 は、KV の書き込みが、TTL が既定の 60 秒のとき、全リージョンで p99 70 秒以内に読めることを求める。正本は東京だけにある（[ADR-0024](0024-kv-central-store-dynamodb.md)）。遠いリージョンからの正本への往復は 100ms 以上かかりうる（見込み。未検証。E7 の `kv-consistency-checker` で測る）。

本家（2026-09-27 に確認）：

- ローカルのキャッシュ、リージョンの層、中央の 3 段。リージョンの層がミスの約 30% を解決する。最も読まれるキーはメモリで 1ms 未満（[We made Workers KV up to 3x faster](https://blog.cloudflare.com/faster-workers-kv/)、2024-09-26）。
- `cacheTtl` は既定 60 秒、最小 30 秒。存在しないキーの結果も同じ遅れでキャッシュする（[How KV works](https://developers.cloudflare.com/kv/concepts/how-kv-works/)、[Read key-value pairs](https://developers.cloudflare.com/kv/api/read-key-value-pairs/)）。

段を重ねたキャッシュで、段ごとに TTL を持つと、古さの上限は段の数だけ伸びる（2 段で最悪 120 秒）。これでは NFR-009 を守れない。

## Options

1. **2 段（ノードの L1、リージョンの L2）。各項目に正本から取った時刻 `fetched_at` を持たせ、どの段でも `now - fetched_at < cacheTtl` のときだけ返す**
2. **2 段で、段ごとに TTL を持つ**（L1 は短い TTL、たとえば 10 秒）
3. **リージョンの L2 だけ**（ノードにキャッシュを持たない）
4. **書き込みのたびに全リージョンへ無効化を送る**（TTL は保険）

## Decision

1 を採用する。

- L1：各ノードの外向きのプロキシのメモリ（1 GiB。1 MiB を超える値は置かない）。L2：各リージョンの ElastiCache for Valkey。
- `fetched_at` は、正本から読んだ時刻。L2 から L1 へ写しても引き継ぐ。
- 存在しない・墓石・期限切れのキーは `absent` としてキャッシュする（負のキャッシュ）。
- 書いたリージョンでは、書き込みの確定の後に L2 と、書いたノードの L1 を新しい版で上書きする（ADR-0005）。
- キャッシュは、手元の版より新しい版でだけ上書きする。
- L2 の項目の年齢が `cacheTtl` の半分を超えて読まれたら、裏で取り直す（先読み）。同じキーのミスは 1 本にまとめる。
- 正本の読み込みが 2 秒で返らない・失敗したら、`cacheTtl` を過ぎた L2 の値を返し、`cacheStatus` で古いことを示す（古くても返す段）。この段に入った回数を警報にする。
- 2 を採らない理由：古さの上限が `cacheTtl` と L1 の TTL の和になる。L1 の TTL を短くすると、L1 の当たりの率が下がる。
- 3 を採らない理由：最も読まれるキーでも、毎回リージョンの中の往復（1ms 前後の見込み。採らない案なので測らない）が要る。本家はメモリで 1ms 未満を出している。
- 4 を採らない理由：全リージョンへの確実な配信と順序の管理が要り、約束（結果整合）に対して重い。落ちた無効化の扱いで結局 TTL に頼る。S2 で、見えるまでの時間を縮める要望が強ければ、最善の努力の無効化として見直す。

## Consequences

- 良くなること：
  - 古さの上限が `cacheTtl`（＋取り直しの時間）で決まり、段の数に依らない。
  - 同じノード・同じリージョンの中で、読み込みの版が戻らない（内部の不変条件）。
  - 東京の正本の障害でも、読み込みを止めずに返せる。
- 引き受けるコスト：
  - 古くても返す段では、NFR-009 を破る。回数を SLI にして、事象として扱う。
  - 各リージョンに Valkey のクラスタを持つ費用（[capacity.md](../architecture/capacity.md) の 9 節で月 約 2,800 ドルと見積もった。cache.r7g.large の定価から）。
  - 1 MiB を超える値は L1 に置かないので、L2 の往復が要る。

## Confirmation

- 性質ベーステスト：任意の書き込み・読み込みの列で、キャッシュが返す値の `fetched_at` が `now - cacheTtl` より新しい（古くても返す段を除く）。L1・L2 の版が減らない。
- 障害の注入の試験：L2 の障害、東京への経路の遅延の中で、有界の古さの検査器が違反を 0 件と判定する。
- 本番の計測：全リージョンの合成の書き込みと読み込みで、見えるまでの時間の p99 が 70 秒以内（NFR-009）。
