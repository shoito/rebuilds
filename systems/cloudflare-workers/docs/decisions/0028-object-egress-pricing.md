# ADR-0028: オブジェクトストレージの外向きの転送は無料にせず、原価を下回らない従量で課金する

詳細は [object-storage.md](../architecture/object-storage.md) の 10 節。

## Context

本家の R2 は、外向きの転送を無料にし、保存 0.015 ドル/GB-月、Class A 4.50 ドル/100 万、Class B 0.36 ドル/100 万で課金する（[R2 pricing](https://developers.cloudflare.com/r2/pricing/)、2026-09-27 に確認）。これは R2 の最大の売りである。

この題材は S1・S2 を AWS の上で動かす（ADR-0003）。AWS の東京の定価（価格表の API、2026-09-26 の公開分、2026-09-27 に確認）：

- S3 Standard 0.025 ドル/GB-月、PUT 系 4.70 ドル/100 万、GET 0.37 ドル/100 万。
- インターネットへの転送 0.114 ドル/GB（最初の 10 TB）から 0.084 ドル/GB（150 TB 超）。
- Global Accelerator を通る転送には、DT-Premium が EC2 の転送の料金に上乗せされる（[Global Accelerator pricing](https://aws.amazon.com/global-accelerator/pricing/)）。アジア太平洋のリージョン（東京を含む）からアジア太平洋の利用者へは 0.010 ドル/GB（価格表の API の `AP-AP-OUT-Bytes-Internet`、2026-09-27 に確認）。

原価だけで、保存・操作とも本家の料金を上回る。転送を無料にすると、公開の配信の多い利用者 1 人（月 200 TB）で、転送だけで約 18,000 ドルの原価になる。本家が転送を無料にできる原価の構造（自前の網と相互接続）は、この設計にはない（本家の内部は公開されていない）。

## Options

1. **保存・操作・インターネットへの転送の従量にし、転送に無料の枠を付ける。値は原価を下回らない**
2. **本家と同じく転送を無料にし、保存と操作の料金に転送の原価を均して載せる**
3. **転送を無料にし、公平な利用の上限（超えたら制限）を付ける**

## Decision

1 を採用する。

- 課金の単位：保存（GB-月、標準と低頻度）、書き込み系の操作、読み込み系の操作、インターネットへの転送（GB）。
- 転送として数えるもの：S3 の API の口と公開の配信（カスタムドメイン、開発用の URL）から、インターネットへ出た本文の量。
- 転送として数えないもの：関数のバインディングの読み込み（関数の応答として外へ出る分は、関数の転送の扱いで、limits-and-billing で決める）。
- 値（円）と無料の枠は limits-and-billing で決める。各項目の単価は、AWS の原価（段階の料金、DT-Premium、大阪への複製）を下回らない。
- 利用者への説明で「転送は無料」を掲げない。日本の利用者への近さと関数との統合を価値にする。
- 2 を採らない理由：転送の多い利用者の原価を、転送しない利用者が払う。公開の配信に偏った利用者が集まると、赤字が膨らむ。
- 3 を採らない理由：上限を超えた時点での制限は、公開のサイトの停止になり、利用者の信頼を失う。上限の値を決める根拠もない。

## Consequences

- 良くなること：
  - 利用の偏りで赤字にならない。intent の K8（採算）を守りやすい。
  - 原価の変化（S2 のリージョン、S3 の自前の PoP）に合わせて、転送の単価を下げられる。
- 引き受けるコスト：
  - 本家からの乗り換えの理由として、価格では勝てない。本家の R2 と比べられたときの説明が要る。
  - 転送の量を、ゲートウェイと入口のプロキシで正確に数える仕組みが要る（キャッシュから返した分も数える）。
  - CloudFront の定額の計画は実在する（Premium は月 50 TB で 1,000 ドル。1 つの配信と 1 つの apex だけ、多数のテナントの配信は対象外。[object-storage.md](../architecture/object-storage.md) の 10 節、2026-09-27 に確認）。開発用の URL の配信に当てられるか（規約と 1 つの apex の制限）は未検証。S2 の前に調べ、当てられるならこの ADR を見直す（**PM の確認事項**）。

## Confirmation

- limits-and-billing の料金の表を決めるとき、各項目の単価が、この ADR の原価の計算（東京の定価、段階、DT-Premium、複製）を下回らないことを、PM と経理の確認で確かめる。
- 転送の計量：合成の公開の配信で、送った本文の量と、計量の値の差が 1% 未満。

## 注記（2026-09-27、統合の工程）

- 「関数の応答として外へ出る分」は、limits-and-billing で、同じ外向きの転送の行（1GB 25 円、有料に 10GB を含む。無料は 1 日 500MB）で数えると決めた。関数の応答は入口のプロキシが、サブリクエストの送信は外向きのプロキシが数える（[limits-and-billing.md](../architecture/limits-and-billing.md) の 5.1 節と 6.3 節）。
