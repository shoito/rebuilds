# ServiceNow

企業の IT 部門が、障害の受け付け・原因の調査・変更の承認・社員からの依頼・構成の管理を 1 つの記録の上で回すための IT サービス管理（ITSM）の基盤を、「メタデータで拡げられる記録の基盤」と「止まらない、数え間違えないワークフローと SLA」として作り直す設計。

主な論点：

- 継承できるテーブルの階層と、テナントが足すフィールド・テーブル（メタデータ駆動）
- ノーコードのワークフローと承認の耐久性、状態の遷移を 1 回だけ行うこと
- 業務カレンダーと日本の祝日の上での SLA の計時
- 複数の取り込み元からの CMDB の識別と調整（重複を作らない）
- テーブル・レコード・フィールドの単位のアクセス制御
- テナントの分離（共有の基盤と、大口の専用のセル）
