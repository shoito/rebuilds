# ADR-0020: 内閣府の祝日の CSV を定期に取りに行き、法の規則との突き合わせと人の承認を経てバージョンとして公開する。収録の範囲の外は祝日なしで計算し、後で計算し直す

詳細は [sla-and-calendars.md](../architecture/sla-and-calendars.md) の 5 節。

## Context

[ADR-0004](0004-workflow-and-sla-engine.md) は、日本の祝日を内閣府の CSV から取り込んだバージョン付きの表にすると決めた。[AGENTS.md](../../AGENTS.md) は、祝日のデータをコードに埋め込まず、テストでは固定のバージョンを使うことを求める。[intent.md](../intent.md) は、翌年の祝日の公表の時期と CSV の利用の条件を、この領域で確かめるとした。

内閣府は、1955 年から 2027 年までの祝日の CSV を公開し、翌々年（2028 年）の分を前年の 2 月に掲載するとしている（[国民の祝日について](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)、2026-09-28 に確認）。CSV は Shift_JIS で、振替休日と国民の休日は名称が「休日」になる（CSV を取得して確認）。ページに利用の条件の記載はない。内閣府のサイトの利用規約は、権利の表記のないコンテンツに公共データ利用規約（第 1.0 版）を当てる（[内閣府ホームページ利用規約](https://www.cao.go.jp/notice/rule.html)、2026-09-28 に確認）。この規約は商用の利用を認め、出典の記載と、加工したときはその旨の記載を求め、数値のデータや簡単な表は著作権の保護の対象でないとする（[公共データ利用規約（第 1.0 版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)、2026-09-28 に確認）。祝日法の第 3 条第 2 項（振替休日）と第 3 項（国民の休日）の文言は同じページで確かめた。

祝日は法の改正や特例（オリンピックの年の移動など）で変わりうる。過去の日付の変更は、すでに終わった計時の結果に関わる。

## Options

### 取り込み

1. **定期に取りに行き、内容のハッシュが変われば草案を作り、検証と人の承認で公開する**
2. 定期に取りに行き、検証を通れば自動で公開する
3. 年に 1 回、運用者が手で取り込む

### 収録の範囲の外

- a. **祝日なしで計算し、印を付け、新しいバージョンで計算し直す**
- b. 祝日の規則（ハッピーマンデーなど）から先の年の祝日を推定する
- c. 範囲の外に期限がかかる計時を始めない

## Decision

1 と a を採用する。

- 月に 1 回（2 月は毎週）CSV を取得する。SHA-256 が同じなら何もしない。
- 検証 DT-HOL-001：見出し、日付の正しさと重複、年の連続、法の規則から求めた振替休日・国民の休日と「休日」の行の一致（不一致は止めずに強く示す）、過去の日付の変更（2 人目の承認を要る）、件数の大きな減少（止める）。
- 草案のバージョンを作り、差分を運用者（Ops）が見て承認し、公開する。前のバージョンは残す。
- `latest` を参照するカレンダーの新しいバージョンを作り、動いている計時を計算し直す。
- 収録の範囲の外の日付は祝日なしで計算し、計時の行に `calendar_coverage_exceeded` を立てる。収録の残りが 10 か月を切ったら知らせる。
- 取り込んだ CSV の原本をバージョンごとに S3 に置く。テストは固定のバージョンの CSV のファイルを読む。

2 を採らない理由：取得の元の誤り（途中で切れたファイル、形式の変更）や法の特例で、誤った祝日が全テナントの SLA に即座に効く。年に 1〜2 回の変更に人の確認を挟む費用は小さい。

3 を採らない理由：特例の法律による年の途中の変更を取りこぼす。

b を採らない理由：春分の日・秋分の日は前年の 2 月の官報で決まり、規則だけでは確定しない。推定が外れると、期限が後から動く。祝日なしで計算しても、後で計算し直すので、推定より誤りの説明が簡単である。

c を採らない理由：数か月にわたる変更の SLA が始められない。

## Consequences

- 良くなること：
  - 祝日の変更が、差分の確認とバージョンの記録を経て入り、どのバージョンで計算したかを計時ごとに説明できる。
  - 過去の日付の変更を見落とさない。
- 引き受けるコスト：
  - 運用者の承認の手順（年に数回）と runbook が要る。
  - 収録の範囲の外に期限がある計時は、後で期限が前に動きうる（祝日が入ると期限は後ろに動くので、実際には違反が早まることはない。祝日が消える改正のときだけ前に動く）。
  - 出典（内閣府の CSV の URL と公共データ利用規約）を、祝日のバージョンの記録と管理の画面に記載する。規約の当てはめの判断は法務の L9 に残す（この ADR は判断しない）。
