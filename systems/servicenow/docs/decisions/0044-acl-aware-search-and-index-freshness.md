# ADR-0044: 検索は ACL の述語の索引で表せる部分を絞り込みにし、返す直前に DB で行とフィールドの読み取りを確かめ直す。一致と強調を読めるフィールドに限り、総数を出さない。索引は DB の今の行を外部のバージョンで入れる

詳細は [search.md](../architecture/search.md) の 6・7 節。

## Context

[access-control.md](../architecture/access-control.md) の 6.2 節の 9 行は、検索の出口で「索引の ACL の属性で絞った後、返す直前に各結果を判定の関数で確かめ直す。読めないフィールドの一致の強調を出さない」と決めた。[ADR-0012](0012-acl-enforcement-at-every-exit.md) は、読めない値を件数・順序・集計からも推測させないと決めた。行の規則の条件は SQL の述語にコンパイルできる形に限られる。

検索の索引は写しで、遅れる。削除・権限の変更・本文の変更の後も、しばらく古い文書が残る。outbox の配送は少なくとも 1 回で、SQS の標準のキューは順序を保たない。

本家の検索の ACL の効かせ方は、公開の資料で確かめられなかった（未検証。本家の振る舞いで、この決定の前提ではない）。

## Options

### ACL の効かせ方

1. **索引の近似の絞り込み（広めに取る）＋ DB での確かめ直し**
2. 索引に「読める主体の集合」を焼き込む（文書ごとの読み手の一覧）
3. 索引の絞り込みだけ（確かめ直しなし）
4. DB で読める行の ID を全部求めてから、索引に渡す

### 総数

- a. **出さない。「さらにあるか」だけ**
- b. OpenSearch の総数を出す

### 反映

- x. **事象で ID を受け、DB の今の行を外部のバージョンで入れる**
- y. 事象の本文をそのまま入れる

## Decision

1、a、x を採用する。

- 行の述語を、索引で表せる要素（索引の型付きの列の比較、`now` の相対、論理の結合）は絞り込みに写し、表せない要素（1 段の参照のたどり、索引にない列）は索引では真として扱う（広めに取る方向にだけ近似する）。
- 上位 N 件（1 ページ × 3、最大 150）を取り、Aurora の reader で `id = ANY($ids) AND 行の述語` を確かめ、一致したフィールドの行ごとの読み取りを確かめる。足りなければ最大 3 回まで次を取る。
- 一致は、ロールだけで読めると決まるフィールドの集合に限る（入れ子の `fid ∈ V`）。レコードの条件で決まるフィールドは、確かめ直しで読めない行では、そのフィールドだけの一致の行を落とす。強調は読めるフィールドの断片だけ、索引のバージョンが DB のバージョンと等しい行だけ。
- OpenSearch の総数とファセットを出さない。
- 反映は outbox の `record.changed` → SQS → Indexer。Indexer は DB の今の行を読み、`version_type = external` で行の `version` を付けて入れる。古いバージョンの書き込みの拒否は成功として捨てる。
- 目標：索引の遅れ p95 5 秒・p99 30 秒。日次の抜き取りの突き合わせ。

2 を採らない理由：読み手の集合は、ACL の規則・ロール・グループの所属の変更のたびに、大量の文書の入れ直しを要る。人事の一括の取り込みで `acl_version` が上がると、テナントの全文書が対象になる。

3 を採らない理由：1 段の参照のたどりのような表せない条件を落とすと、読めない行が出る。索引の遅れで、権限を外した行や削除した行も出る。

4 を採らない理由：大きなテナントで読める行が数百万になり、ID の集合を索引に渡せない。

b を採らない理由：総数は確かめ直しの前の数で、読めない行を含む。「自分に見えない何件かに語が含まれる」ことを推測させる。

y を採らない理由：事象の重複・逆転・欠けで、古い本文が残りうる。今の行を読めば、最後の事象の処理で必ず今の行になる。

## Consequences

- 良くなること：
  - ACL と索引の遅れの両方の誤りを、DB の確かめ直しの 1 か所で閉じる。
  - ACL の規則の変更で索引を作り直さない。
- 引き受けるコスト：
  - 検索ごとに DB の問い合わせが 1〜3 回増える。reader で受ける。
  - 総数が出ない。担当者の使い勝手を E9 で確かめる。
  - 近似が粗いテーブルでは、確かめ直しで多くの行が落ち、繰り返しが増える。落ちた割合を計測する。
