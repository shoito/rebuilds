# ADR-0061: セルは S1 の負荷の半分を 1 つの Aurora の writer で受ける大きさにし、9 時のタイマーの山は優先度・定期のトリガーのばらつき・平日 8:50 の予定の台数の拡大で受ける。優先度 2・3 の遅れは山の間 5 分まで許す

詳細は [capacity.md](../architecture/capacity.md)。

## Context

S1 は共有のセル 2 つで、セルごとに Aurora の writer 1 台＋reader 2 台（[architecture/README.md](../architecture/README.md) の 2 節）。タイマーの発火は平日 9 時に集中する（同じ文書の 2・6 節）。タイマーは 1 つの表で、フロー・承認・SLA が共有する（[ADR-0004](0004-workflow-and-sla-engine.md)）。優先度とテナントの取り分は [ADR-0018](0018-flow-limits-and-tenant-fairness.md) で決めた。NFR-003 は SLA の警告と違反の発火を期限から p99 60 秒以内に求める。

山の大きさは本家の資料で確かめられず（未検証。E4 `timer-burst-generator` と E12 `timer-burst-load-test` で計測して置き換える）、この題材の見積もりで置くしかない。

## Options

### 山の受け方

1. **優先度とテナントの取り分（既存）＋定期のトリガーのばらつき＋予定の台数の拡大。低い優先度の遅れを山の間は許す**
2. すべての優先度で p99 60 秒を守る大きさにする（writer を大きくし、engine を多くする）
3. タイマーの表を別の DB（セルの外）に移す

### 見積もりの置き方

- a. **動いているタイマーの 5% が 9:00〜9:15 に、その半分が最初の 1 分に来る**
- b. 平均の負荷の 3 倍で置く

## Decision

1 と a を採用する。

- 1 セルの山：タイマー 20 万（最初の 1 分に 1,667 件/秒、うち優先度 0 が 333 件/秒）、保存 98 件/秒、書き込み 約 9,700 行/秒。writer `db.r8g.4xlarge` の CPU 70% 以下を目標にする（E4 で計測）。
- engine はピーク 6 タスク（同時のトランザクション 8 本ずつ）、最大 24。平日 8:50 に予定で上げ、10:30 に戻す。国民の祝日には予定を止める。
- フローの時刻のトリガーと日次のジョブに、テナント・フローの ID のハッシュで 0〜5 分のばらつきを足す。SLA と承認の期限には足さない。
- 優先度 0・1 は p99 60 秒、優先度 2・3 は山の間 p99 5 分（案）。
- 超えるときは、取得の上限で平らにする → writer を上げる → セルを足す、の順。

2 を採らない理由：1 日の 15 分のために、writer と engine を大きく持つ。フローのステップや一括の処理が数分遅れても、業務への影響は小さい（SLA の違反の時刻は期限の時刻で決まり、遅れで変わらない。[ADR-0021](0021-sla-definitions-and-timers.md)）。

3 を採らない理由：タイマーの発火と、レコード・計時の行・outbox の更新を 1 つのトランザクションで行う設計（ADR-0004）が崩れる。

b を採らない理由：タイマーの山は、平均の負荷ではなく、時刻の固まり（9:00 ちょうど）で決まる。平均の倍率では、最初の 1 分の集中を表せない。

## Consequences

- 良くなること：
  - SLA の約束（NFR-003）を、山の中でも優先度で守れる。
  - 1 日の山のために常に大きな構成を持たない。
- 引き受けるコスト：
  - 定期のトリガーの時刻が、指定から最大 5 分ずれる。画面に示す。
  - 見積もりが外れると、山の中の低い優先度の遅れが延びる。E4・E12 の試験と、本番の最初の 3 か月の実測で置き換える。

## Confirmation

- 負荷試験（E4 は `timer-burst-generator` の仮の構成、E12 は `timer-burst-load-test` の本番の構成）：優先度 0 の p99 60 秒、期限を過ぎた未発火の違反 0、writer の CPU 70% 以下。
- 本番の監視：9 時の山の遅れの系列（[observability.md](../architecture/observability.md) の 3.3 節）。
