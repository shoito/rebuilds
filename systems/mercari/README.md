# Mercari

個人どうしが中古の品を売り買いするフリマのアプリを、「写真から数十秒で出せる出品と、検査を通した出品の公開」「売れた品も引ける日本語の検索と、保存した検索の新着の通知」「一品を一回だけ売る購入と、支払い・発送・受取評価・評価・売上金の振り替えまでの期限つきのステートマシン」「預かりと手数料と売上金を持つ複式簿記の台帳と、振込・ポイント」「住所を相手に見せない運送会社との連携」「偽ブランド・禁止品・不正を見つける T&S のパイプライン」として作り直す設計。日本を最初の市場にする。

主な論点：

1. 出品：写真の受け取りと処理、カテゴリ・状態・ブランド、価格の提案（ML の境界）、出品の質の検査
2. 検索と発見：日本語の全文検索、絞り込みと集計、売れた品の検索、保存した検索と新着の通知（大きな fan-out）、おすすめ
3. 取引：購入 → 支払いの預かり → 発送 → 配達 → 受取評価 → 相互の評価 → 売上金への振り替えのステートマシン、キャンセル・紛争・運用の介入と期限、コメントでの値下げ交渉、並行の下で一品を一回だけ売ること
4. 預かりと売上金：買い手の支払い・手数料・売り手の残高の台帳、売上金の期限、口座への振込、売上金・ポイントでの購入、資金決済法の枠組み（法務の確認待ち）
5. 配送：運送会社との匿名の配送（QR・番号の発行、追跡、サイズと料金）、住所の秘匿、配送の状態の Webhook
6. 売り手と買い手のメッセージ：商品のコメントと取引のメッセージ、悪用の絞り込み
7. T&S：偽ブランド・禁止品・盗品の検出（画像と文字の分類器と人の審査）、不正（乗っ取り、偽の発送、チャージバック）、本人確認（eKYC）、評価と信用、通報、情報流通プラットフォーム対処法、古物営業法
8. 通知（プッシュとメール）と、値下げ・いいねの fan-out
9. アカウント：電話番号の確認、セッション、端末
10. 日本の法令（資金決済法、特定商取引法、景品表示法、個人情報保護法、古物営業法、取引デジタルプラットフォーム消費者保護法、インボイス、犯罪収益移転防止法など）。法務の確認待ち
