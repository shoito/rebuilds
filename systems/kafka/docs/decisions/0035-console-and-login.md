# ADR-0035: コンソールは管理 API を呼ぶ SPA にし、ログインは Better Auth で、MFA は重要な操作の前に求める

## Context

コンソールは、論理クラスタ・トピック・API キー・ACL・請求を操作する。API キーを作れるので、乗っ取られると、テナントのデータを読み書きされる。一方で、SC-3（登録から最初のメッセージまで 5 分）を満たす必要がある。

rebuilds の他の題材の決定（いずれも 2026-09-27 時点）：

- Slack：ログインは Better Auth を自前でホストし、パスワードを持たない（Slack の [ADR-0012](../../../slack/docs/decisions/0012-self-hosted-auth-with-better-auth.md)）。
- Stripe：ダッシュボードは公開 API を呼ぶ SPA にし、第三者のスクリプトを読み込まない（Stripe の [ADR-0028](../../../stripe/docs/decisions/0028-dashboard-architecture.md)）。MFA を全員に必須にする（Stripe の [ADR-0008](../../../stripe/docs/decisions/0008-api-keys-and-dashboard-access.md)）。

## Options

作り：

1. **管理 API（`/v1`）をそのまま呼ぶ SPA。コンソールだけのものは `/console/...`**
2. コンソール専用の BFF

MFA：

- A. 全員に、ログインのときに必須（Stripe と同じ）
- B. **重要な操作の前のステップアップで求める。組織の設定で全員に必須にもできる**
- C. 利用者の任意

## Decision

1 と B を採用する。詳細は [console-and-api.md](../architecture/console-and-api.md) の 4・5 節にある。

- **作り**：React・TanStack Router・TanStack Query の SPA。管理 API と同じハンドラー・`authorize()`・冪等・監査を通る。CSP は `script-src 'self'` で、第三者のスクリプトを読み込まない。
- **ログイン**：Better Auth（メールの OTP、Google、パスキー）。パスワードは持たない。
- **ステップアップ**：API キーの作成・削除、ロール・招待・サービスアカウントの削除、論理クラスタの削除、IP の許可リストの変更、支払いの方法の変更の前に、直近 10 分以内のパスキーか TOTP を求める。最初の API キーの作成で、パスキーの登録を案内する。
- **組織の方針**：組織の設定で「MFA を全員に必須」にすると、ログインのたびに求める。
- **セッション**：アイドル 24 時間、絶対 14 日。
- **SSO**：SAML・OIDC は S2。

2 を選ばない理由：Stripe の ADR-0028 と同じく、検証・冪等・監査の経路が 2 つになり、コンソールだけの抜け道が生まれうる。

A を選ばない理由：登録の直後に MFA の登録を求めると、SC-3 の 5 分を圧迫し、試したいだけの開発者が離れる。お金を直接動かす Stripe と違い、登録の直後に守るべき資産（API キー、データ）はまだない。守るべき操作の前に求めれば、乗っ取りの影響を抑えられる。

C を選ばない理由：API キーを作れる画面を、1 つ目の要素（メールの OTP）だけで守ることになる。

## Consequences

- 良くなること：
  - 最初の 5 分を守りつつ、API キーとアクセスの変更は 2 つの要素で守れる。
  - コンソールで見つかった管理 API の不足が、そのまま API の改善になる。
- 引き受けるコスト：
  - ステップアップの状態（直近の 2 つ目の要素の時刻）をセッションに持ち、操作ごとに確かめるミドルウェアを保つ。Better Auth の既定の 2 要素の振る舞いには頼らない（Slack・Stripe で確かめたとおり、OTP・ソーシャル・パスキーのサインインで 2 要素目を求めないため）。
  - 第三者の計測を使わず、導入の計測を自前で作る。

## Confirmation

- 表駆動テスト：重要な操作とステップアップの条件の表。
- 結合テスト：ステップアップなしのセッションで API キーを作ると 403（`step_up_required`）。
- CI：ビルドの成果物の HTML と CSP の見出しに、`self` 以外のスクリプトの読み込み先がない。
- E2E：最初の 5 分の手順が、ステップアップを含めて 5 分以内に終わる。
