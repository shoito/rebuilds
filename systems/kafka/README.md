# Kafka

アプリの開発者とデータのチームが、分散ログのクラスタを自前で運用せずに済むマネージドのストリーミング基盤を、「既存のクライアントがそのまま動く互換性」と「受け付けた書き込みを失わない耐久性」として作り直す設計。Apache Kafka のワイヤープロトコルに互換で、形は Confluent Cloud に寄せる。製品の名前・ドメイン・CLI には、本家の名前を使わない（[リポジトリ共通の ADR-0006](../../docs/decisions/0006-brand-neutral-identifiers.md)）。
