# ADR-0011: 削除は印と削除の束で表し、15 日で確定して 24 時間以内に消す。ごみ箱の間は索引と一意の行を外す

詳細は [data-storage.md](../architecture/data-storage.md) の 5 節。

## Context

intent は「項目やオブジェクトを削除しても、一定の期間は復元できる。削除を確定するまで、データを消さない」とする。レコードも同じく、誤った削除から戻せる必要がある。

本家（2026-09-28 に確認）：

- 削除は IsDeleted の印で、15 日は戻せる。主従の親を戻すと子も戻る（[Platform Multitenant Architecture](https://architect.salesforce.com/docs/architect/fundamentals/guide/platform-multitenant-architecture.html)）。
- ごみ箱の行も DB に残り、問い合わせは除外する必要があり、性能に響く。ごみ箱は保存の容量に数えず、件数の上限もない。15 日の後に完全な削除の予定に入るが、時刻は保証しない。一括の API に、ごみ箱を通らない完全な削除がある（[Best Practices for Deployments with Large Data Volumes](https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_large_data_volumes_bp.pdf)）。
- 自分が消したレコードは、そのレコードを読める人が戻せる。他の人が消したレコードを戻すには「すべてのデータの編集」が要る。ごみ箱のレコードはストレージに数えない（[View, Restore, and Manage Items in the Recycle Bin](https://help.salesforce.com/s/articleView?id=xcloud.home_delete.htm&type=5)、2026-09-28 に確認）。ごみ箱の間の一意の値の扱いは公開の資料に書かれていない（未検証。E3 の `recycle-bin-and-purge` で試用の組織で確かめる）。

決めること：ごみ箱の間のピボット・一意・参照の扱い、戻す単位、確定の後に消し終える期限。

## Options

1. **印と削除の束。ごみ箱の間は索引と一意の行を外し、関係・長いテキスト・共有の行は残す。戻す時は束の単位で全部か無しかで作り直す。確定から 24 時間以内に消す**
2. 印だけにし、ピボットは全て残す（一意の値もごみ箱の間は持ち続ける）
3. 削除したレコードを別の表（ごみ箱の表）へ移す

## Decision

1 を採用する。

- 削除は `deleted_at` と `delete_batch_id` を入れ、主従の子も同じ束に入れる。参照の子は `set_null` なら値を空にして束に記録し、`restrict` なら削除を断る。
- ごみ箱の間は、`record_index_values` と `record_unique_values` の行を消す。一意の値を放すので、同じ外部 ID で作り直す連携を止めない。
- 戻すのは束の単位で、全部か無しかにする。親がごみ箱の主従の子だけ、一意の衝突、オブジェクトの削除中は拒否する。
- 15 日で確定する。確定から 24 時間以内に、`records`・ピボット・長いテキスト・共有の行・記録を全て消す。管理者と、削除した本人は、ごみ箱を空にできる。
- 完全な削除は、専用のシステムの権限を持つ一括のジョブだけに許す。
- 2 は、ごみ箱の行が索引の走査と一意の検査に残り、本家が書く性能の問題をそのまま持つ。3 は、削除と戻すのたびに行を 2 つの表の間で移し、共有の行・関係の ID を付け替えることになる。

## Consequences

- 良くなること：
  - ごみ箱の行が、索引の走査と一意の検査を重くしない。
  - 確定の後に消し終える期限が決まる。
  - 戻すが全部か無しかで、半端な状態が残らない。
- 引き受けるコスト：
  - 戻す時に一意の値が衝突しうる。管理者が片方を直す。
  - 戻す時にピボットの行を作り直すので、大きな束の戻すはトランザクションの上限に当たりうる。一括のジョブへ案内する。
  - 15 日と 24 時間は法務の L5 の結論で変わりうる。

## Confirmation

- 決定表：削除の振る舞い、戻すの表（親・一意・削除中・参照先）を表駆動テストにする。
- 性質ベーステスト：任意の削除と戻すの列で、戻した後のレコード・ピボット・参照が削除の前と一致する（例外の行を除く）。
- 結合テスト：確定から 24 時間以内に、全ての表から行が消える。
- 本番：消去の遅れの件数を数え、0 を保つ。
