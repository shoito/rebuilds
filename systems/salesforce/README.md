# Salesforce

B2B の営業チームが、顧客・商談・活動を記録し、会社ごとの業務に合わせて項目・画面・自動化・権限を変えられる CRM（Sales Cloud に相当）を、「メタデータで動く共有の実行基盤」として作り直す設計。

主な論点：メタデータで動く実行基盤（ユニバーサルなデータ辞書）、1 つの共有 DB でのカスタムオブジェクトの保存、レコードの共有とアクセスの再計算、テナントごとの実行の上限（ガバナ制限）、Sandbox からの安全なメタデータのデプロイ。
