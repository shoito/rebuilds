# Datadog

メトリクス・ログ・トレースを受け取り、モニター・ダッシュボード・SLO・インシデントで使えるようにする、複数のテナントの可観測性の SaaS を、「エージェントと OTLP の取り込み、背圧とテナントごとの割り当て」「自前の時系列の保存のエンジン（圧縮、時間で区切るブロック、ロールアップ、S3 の保持の層）とクエリのエンジン」「列指向とブルームフィルターのログの保存と検索」「テールサンプリングとトレースの組み立て」「数百万のモニターを決定的に評価するエンジン」として作り直す設計。日本を最初の市場にする。
