# ADR-0043: 返金の額は、返品・取り消しの単位の `paid_amount`（注文の写しの単位ごとの支払いの額）の和に、事業者が選んだ送料の返金と、返品の手数料の差し引きを足して決める。割引の条件を満たさなくなっても、割引を取り戻さない。返金の税は、独立の方式と再計算の方式の両方を計算できる形にし、どちらを使うかは法務の確認（L4）の後に決める

## Context

- 返金の額は、参照の計算と 1 円も違わない（NFR-013）。割引を按分した注文では、返す単位の支払いの額が単位ごとに違う。
- 返品で、注文の割引の条件（最低の金額）や送料の無料の閾値を下回ることがある。
- 返品の後の税額の決め方は 2 つある（[quality.md](../quality.md) の 2.2.1 節 D）。返還インボイスの記載に効く。法務の確認待ち（L4）。
- 単位ごとの按分は、注文の時に写しへ残している（[ADR-0033](0033-discount-allocation-and-rounding.md)）。

## Options

返金の額：

1. **単位の `paid_amount` の和。割引を取り戻さない**
2. 返品の後の注文を最初から計算し直し、差を返す
3. 単価から割引の比を掛けて計算する

税：

- a. **2 つの方式の両方を計算できる形にし、選択は法務の後**
- b. 今、独立の方式に決める

## Decision

1 と a を採用する。詳細は [returns-and-refunds.md](../architecture/returns-and-refunds.md) の 5・6 節。

- 返す単位の選び方：同じ行の中で、返さない単位を残し、単位の番号の大きい方から返す。単位ごとの `paid_amount` は決まっているので、選び方で額が変わるのは端数の 1 円だけである。
- 返金の額 `R = Σ 返す単位の paid_amount + 送料の返金 − 返品の手数料`。送料の返金は、事業者が 0〜元の送料（送料の割引の後）から選ぶ。返品の手数料は事業者が入れる税込みの額（10% の課税の対価として扱う。区分は法務の L4）。
- 上限：`R ≤ 確定の額 − 既存の返金の和`。注文の行を `FOR UPDATE` で取り、並行の返金で超えない。
- 割引の取り戻し：しない。割引の条件・送料の無料の閾値を下回っても、残りの単位の額を変えない。
- 返金の税：
  - 独立の方式（`independent`）：返す単位の対価を税率ごとに足し、税率ごとに 1 回丸めた額を返金の税額とする。
  - 再計算の方式（`recompute`）：返品の後の注文の税率ごとの対価から税額を計算し、元の税額との差を返金の税額とする。
  - 両方を計算し、`refund_tax_lines` に方式の印をつけて選んだ方を記録する。
  - > 2026-10-10 の注記：統合の工程で、方式の名前を [taxes-and-invoices.md](../architecture/taxes-and-invoices.md) と揃えた。最初の「差分の方式（D）」は「独立の方式（`independent`）」、「再計算の方式（C）」は「再計算の方式（`recompute`）」に改めた（中身は同じ）。ショップの方式の設定は、法務の確認（L4）の後に既定と選択肢を決める。それまでの試験の既定は `recompute`（注文の税額の合計が、返品の後の注文の正しい税額と一致するため）とし、本番の有効化は L4 の後にする。

### 他の案を選ばなかった理由

- **2**：割引の条件を下回ると返金の額が大きく減り、買い手が予測できない。注文の時の規則のバージョンに依存する。
- **3**：端数の扱いが注文の時と違い、1 円ずれる。
- **b**：法令の当てはめを含むので、決めない（[AGENTS.md](../../AGENTS.md)）。

## Consequences

- 良くなること：返金の額が注文の時の記録だけから決まる。
- 引き受けるコスト：割引の条件を返品で抜ける使い方（買ってから返す）を、事業者の手数料で抑えるしかない。
