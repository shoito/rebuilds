# ADR-0059: 関数はアプリのバージョンの一部として公開し、`app-registry` がモジュールを検査し、固定した Wasmtime のバージョンと設定で `.cwasm` に事前に翻訳し、KMS（ECDSA P-256）で署名して S3 に置く。`function-runner` は署名とバージョンを確かめた機械語だけを読み、メモリーとローカルの円盤の LRU に持つ。Wasmtime を上げるときは、全モジュールを新しいバージョンで翻訳し直してから出す

## Context

- [ADR-0008](0008-extension-sandbox-wasm.md) は、事前の翻訳と署名、開発者の機械語を直接読み込まないこと、Wasmtime の更新の流れ（セキュリティの修正を 7 日以内）を決めた。
- `Module::deserialize` は信用した入力にだけ使える。改ざんした機械語を読むと、砂場の外のコードになる。
- チェックアウトの段の中で、モジュールの翻訳（数十〜数百 ms）を待てない（NFR-012 の 1 回 p99 5ms）。

## Options

1. **公開の時に隔離したワーカーで翻訳、KMS で署名、S3、`function-runner` は確かめて読む**
2. `function-runner` が初回の呼び出しで翻訳し、メモリーに持つ
3. 翻訳せずにインタープリターで動かす

## Decision

1 を採用する。詳細は [functions-sandbox.md](../architecture/functions-sandbox.md) の 9 節。

- 検査：輸入の一覧、輸出、メモリーとテーブルの宣言、大きさ（256 KiB）、使える機能、入力のクエリの検証と費用。
- 翻訳：ネットワークのない隔離したタスク、固定の Wasmtime のバージョンと設定。
- 署名：`.cwasm` の SHA-256、Wasmtime のバージョン、設定のハッシュに ECDSA P-256（KMS の鍵は外に出さない）。
- 置き場所：`functions/<app>/<function>/<version>/<wasmtime>.cwasm` と `.sig`。90 日残す。
- `function-runner`：公開鍵で確かめ、バージョンが合うものだけを `deserialize`。メモリー 512 MB と円盤 2 GB の LRU。
- Wasmtime の更新：全モジュールを新しいバージョンで翻訳してから新しいイメージを出す。両方のキーを並べ、段階のデプロイの間は両方が動く。
- フラッシュセールの前に対象のショップの関数を先読みする。

### 他の案を選ばなかった理由

- **2（初回に翻訳）**：初回の呼び出しが p99 を壊す。翻訳器が checkout のタスクの中で悪意の入力を受ける。
- **3（インタープリター）**：燃料 1,000 万が数十 ms 以上になり、NFR-012 を守れない見込み。

## Consequences

- 良くなること：実行の時に翻訳しない。改ざんした機械語を読まない。
- 引き受けるコスト：Wasmtime の更新のたびに全モジュールの翻訳し直し（モジュールの数に比例）。翻訳のワーカーと鍵の管理を持つ。

## Confirmation

- 脱出の試験：書き換えた `.cwasm`、別のバージョンで作った `.cwasm` が読み込まれない。
- IaC の検査：翻訳のワーカーにネットワークがない。`function-runner` の IAM は S3 の読み取りと KMS の公開鍵の取得だけ。
- Wasmtime の更新の訓練：全モジュールの翻訳し直しの時間を測る。
