# ADR-0076: Admin API・Storefront API・Webhook の本文・関数の API は同じ四半期の日付のバージョン（`YYYY-MM`）を持ち、12 か月支え、支えを外したバージョンの要求は支えている最も古いバージョンで答える（繰り上げ）。`loom_version` は消さずに足し、`loom_ir_version` を上げるときは公開中のテーマを背景で翻訳し直してから新しいレンダラーを出す。Wasmtime を上げるときは全モジュールを翻訳し直し、記録した入力で出力と燃料を比べてから出す

## Context

- Admin API は四半期の日付のバージョンを持ち、12 か月支える（[ADR-0009](0009-admin-api-graphql-and-cost-limits.md)）。Storefront API、Webhook の本文、関数の入力のスキーマ（[functions-sandbox.md](../architecture/functions-sandbox.md)）にもバージョンが要る。別々の周期だと、開発者が追う日付が増える。
- 支えを外したバージョンの要求をエラーにすると、更新を忘れたアプリが一斉に止まり、事業者の業務が止まる。
- テーマの言語は、新しい振る舞いを新しい `loom_version` で足し、古い振る舞いを残す（[ADR-0007](0007-theme-language-design.md)）。IR の形（`loom_ir_version`）は内部の形で、レンダラーの更新で変わりうる。古い IR を新しいレンダラーが読めないと、公開中のテーマが描けない（[storefront-themes.md](../architecture/storefront-themes.md) の 11 節）。
- 関数の機械語は Wasmtime のバージョンに結び付き、上げるときは全モジュールの翻訳し直しが要る（[ADR-0059](0059-function-publish-compile-and-distribution.md)）。燃料の数え方が変わると、上限ちょうどの関数の結果が変わりうる。

## Options

1. **API の 4 つを同じ周期にし、繰り上げる。IR と Wasmtime は、先に作り直して比べてから出す**
2. API ごとに別の周期。支えを外したらエラー
3. IR と機械語を、要求の時に作り直す（遅延）

## Decision

1 を採用する。詳細は [delivery.md](../architecture/delivery.md) の 6 節。

- API：`YYYY-MM`（1・4・7・10 月）。リリースの 3 か月前に候補、9 か月で非推奨（`X-<Brand>-Api-Version-Deprecated`）、12 か月で支えを外し、支えている最も古いバージョンで答え、`X-<Brand>-Api-Version` に実際のバージョンを返す。Webhook の本文は購読のバージョンで作り、外れたら繰り上げる。
- 関数の API：公開の時に固定し 12 か月。支えを外す 90 日前から開発者と事業者に知らせる。
- `loom_version`：消さない。足すだけ。
- `loom_ir_version`：(1) 両方の IR を読むレンダラーを出す、(2) 公開中と予約のテーマを背景で翻訳し直し、記録した要求の抜き取りで出力と歩数を比べる、(3) 全部が終わってから古い IR を読まないレンダラーを出す。
- Wasmtime：(1) 全モジュールを翻訳し直して署名し、バージョンのキーで並べる、(2) 記録した入力で新旧の出力（違い 0）と燃料（上限の 10% を超える違いと、上限の超過を報告）を比べる、(3) `checkout` の波で出す、(4) 古い機械語を 90 日残す。セキュリティの修正は 7 日以内（[ADR-0008](0008-extension-sandbox-wasm.md)）。

### 他の案を選ばなかった理由

- **2**：開発者の追う周期が増え、支えを外した日に更新を忘れたアプリが一斉に止まる。
- **3（遅延）**：最初の要求が遅くなり、作り直しの失敗が買い手の要求の中で起きる。比べる機会がない。

## Consequences

- 良くなること：
  - 開発者は 1 つの周期を追えばよい。古いアプリが止まらない。
  - IR と Wasmtime の変更で、公開中のテーマと関数の振る舞いが黙って変わらない。
- 引き受けるコスト：
  - 繰り上げで、古いアプリが新しいバージョンの振る舞いを受け、意図しない違いが出うる（非推奨の知らせで促す）。
  - 4〜5 のバージョンの変換の層と SDL の写しを保守する。
  - IR の翻訳し直しと関数の再生の比べの作業を持つ。
