# ADR-0045: 書き出しは頼んだ人の同期グループで絞って Worker が作り、S3 の非公開の場所に 24 時間置く。取り出しはセッションで本人を確かめてから 5 分の署名付きの URL へ転送し、メールには署名付きの URL を入れない

## Context

intent は CSV への書き出しを MVP に含める。本家は、ビュー・プロジェクト・ワークスペースから CSV を作り、準備ができたらメールでリンクを送る（12 時間で切れる）。ゲストは書き出せず、管理者は非公開のチームを含める選択を持つ（[Exporting data](https://linear.app/docs/exporting-data)、2026-09-28 に確認）。

書き出しは、ワークスペースのデータをまとめて端末の外へ出す経路である。[ADR-0004](0004-tenancy-and-permissions.md) の「同期グループの判定を通らない読み出しを作らない」を守る必要がある。本システムの管理者は、メンバーでない非公開のチームの中身を読めない（[permissions-and-teams.md](../architecture/permissions-and-teams.md) の DT-PERM-001 の行 4）。

## Options

権限：

1. **頼んだ人の主体の `groupsFor` で絞る（管理者も読める行だけ）**
2. 管理者は全部の非公開のチームを含められる

配り方：

- a. **S3 の非公開の場所。メールはアプリの URL だけ、取り出しの時にセッションで確かめて 5 分の署名付きの URL へ**
- b. メールに署名付きの URL（12 時間）を入れる

## Decision

1 と a を採用する。詳細は [import-export.md](../architecture/import-export.md) の 7 節。

- CSV（ビュー・チーム・プロジェクト、5,000 件まで、ゲストを除く）と、ワークスペースの JSON（管理者）を、Worker のジョブで作る。読み出しは公開 API と同じ `packages/query` で、ジョブの始めの `groupsFor` で絞る。途中で主体が停止・脱退したらジョブを失敗にする。
- CSV は値の先頭の `=`・`+`・`-`・`@` などに `'` を付け、式の注入を防ぐ。
- ファイルは KMS で暗号化した非公開のバケットに 24 時間置く。取り出しは `https://<brand>.<domain>/exports/<job_id>` でセッションと頼んだ本人を確かめ、5 分の署名付きの URL へ 302 で転送する。
- 書き出しを監査ログに残す。
- 2 を採らない理由：管理者がイシューを読めない非公開のチームの中身を、書き出しなら読めることになり、権限の定義が 2 つになる。本家の振る舞いは**未検証**。
- b を採らない理由：メールの転送や、メールの事業者の側で URL が漏れると、12 時間は誰でも読める。

## Consequences

- 良くなること：
  - 書き出しが、同期・API と同じ権限で絞られる（NFR-008）。
  - メールが漏れても中身は読めない。
- 引き受けるコスト：
  - 管理者がワークスペースの全部を書き出すには、非公開のチームに参加する必要がある（参加は監査に残る）。
  - 取り出しにログインが要る。

## Confirmation

- 性質ベーステスト：PROP-EXPORT-001（見てよい行だけ）。
- 例示テスト：式の注入の各先頭文字。
- 結合テスト：別の利用者のセッションでの取り出しの拒否、24 時間の後の `404`。
