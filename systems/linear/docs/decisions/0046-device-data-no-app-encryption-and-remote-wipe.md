# ADR-0046: 手元の DB はアプリの層で暗号化せず、OS のディスクの暗号化に任せる。ログアウト・除外・遠隔の消去の指示で手元を消し、共有の端末には「この端末に保存しない」の入り方を置く。Electron のミニダンプを外へ送らない

## Context

クライアントは、ワークスペースの見てよいデータと、未送信の変更（outbox）を IndexedDB に持つ（[ADR-0005](0005-client-persistence-and-offline.md)）。オフラインで起動し、7 日のオフラインの後も送れることが要る（NFR-003・004）。ADR-0005 は「ログアウトでは、そのアカウントのデータベースをすべて消す」と決め、共有の端末と手元の暗号化を security の領域に任せた。

- 端末に残るデータは、共有の端末・紛失・除外された人の端末で漏れうる。
- ブラウザでは、アプリの層の鍵を同じ端末に置くしかない。サーバーから鍵を受ける形は、オフラインの起動と合わない。
- Electron の `safeStorage` は、Windows では同じ利用者の他のアプリから守らず、Linux では秘密の保管がないと守らない（[safeStorage](https://www.electronjs.org/docs/latest/api/safe-storage)、2026-09-28 に確認）。
- 「全部の端末からログアウト」は、他の端末の outbox を守るため、その端末の DB を消さない（[ADR-0035](0035-sessions-and-sync-ticket.md)、[accounts-and-auth.md](../architecture/accounts-and-auth.md) の 6.6 節）。紛失した端末を消す手段がない。

## Options

手元の暗号化：

1. **アプリの層で暗号化しない。OS のディスクの暗号化を前提にする**
2. WebCrypto の鍵（抽出できない `CryptoKey`）を IndexedDB に置き、行を暗号化する
3. サーバーから毎回鍵を受けて暗号化する

紛失した端末：

- a. **遠隔の消去（セッションに印を付け、次にチケットを求めた時に消させる）**
- b. 手段を持たない

## Decision

1 と a を採用する。詳細は [security.md](../architecture/security.md) の 4 節。

- 手元の DB はアプリの層で暗号化しない。紛失・盗難には OS のディスクの暗号化を前提にし、利用の条件と管理者向けの案内に書く。
- 消す契機：この端末からのログアウト（そのアカウントの全部の DB と `localStorage`）、ワークスペースからの除外・停止（そのワークスペースの DB）、遠隔の消去（セッションの `wipe_requested`。チケットの発行で `401 wipe_required` を返し、端末は未送信を確かめずに消す）、アカウントの削除（全部のセッションに `wipe_requested`）。
- 共有の端末：Web のログインの画面に「この端末に保存しない」を置き、IndexedDB を使わずメモリーだけで持つ（オフラインは使えない）。
- Electron の `crashReporter` のミニダンプを外へ送らない。JavaScript のエラーは、スタックと Action の ID とバージョンだけを自前の口へ送る。
- 2 を採らない理由：鍵が同じプロファイルにあり、ディスクを読める攻撃者から守れない。XSS には効かない。行ごとの暗号化で、手元の起動と索引の読み出しが遅くなる（NFR-001・003）。
- 3 を採らない理由：オフラインで起動できなくなり、ADR-0005 の前提が崩れる。
- b を採らない理由：紛失した端末の中身を、端末が戻っても消せない。

## Consequences

- 良くなること：
  - オフラインの起動と入力の速さを落とさない。
  - 紛失した端末が一度でもつながれば消せる。
- 引き受けるコスト：
  - ディスクの暗号化のない端末では、ディスクを読める人に中身が読める。
  - 遠隔の消去は、つながらない端末には効かない。消すと未送信の変更を失う。
  - 共有の端末の入り方は、毎回ブートストラップするので遅い。
  - セッションとチケットの発行の決定表に行が増える（accounts-and-auth の領域への依頼）。

## Confirmation

- 手元の消去の試験（Playwright）：各契機の後に、該当のワークスペースの IndexedDB の DB・`localStorage` のキーが残っていない。
- Electron の配布物の検査：`crashReporter` の `uploadToServer` が偽。
- 本番：遠隔の消去の指示から消去までの時間、消去が届いていない端末の数。
