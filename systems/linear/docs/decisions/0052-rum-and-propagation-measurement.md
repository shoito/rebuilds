# ADR-0052: RUM は自前の口に、端末で集めたヒストグラムを送り、中身と識別子を送らない。伝播は Writer のコミットの直前の時刻を差分と一緒に運び、クライアントは ping の往復で見積もった時計の差で「確定から適用まで」を測る

## Context

NFR-001（入力から描画まで p99 50ms）と NFR-002（確定から他のクライアントの適用まで p99 1 秒）は、どちらも利用者の端末の上の時間である。サーバーの計測だけでは測れない。client-app の領域は、Action の ID ごとの自前の印（[ADR-0018](0018-render-path-and-latency-budget.md)）と、RUM の送り先を法務の L2 と observability の領域で決めることを求めた。sync-engine の領域は、伝播の区間ごとの予算を置いた（[sync-engine.md](../architecture/sync-engine.md) の 7.6 節）。

伝播の「確定」はサーバーの時刻で、「適用」は端末の時刻である。端末の時計はずれている。

## Options

RUM の送り先：

1. **自前の収集の口（`/rum`）と、AMP・S3**
2. 外部の RUM の事業者
3. CloudWatch RUM

伝播の計測：

- a. **Writer のコミットの直前の時刻 `c` を差分と一緒に運び、端末は ping/pong で見積もった時計の差で `(適用 − 差) − c` を測る。加えて合成監視の 2 つのクライアントを同じ時計で測る**
- b. 合成監視だけで測る
- c. サーバーの Gateway の送信までを測り、端末の区間は見積もりで足す

## Decision

1 と a を採用する。詳細は [observability.md](../architecture/observability.md) の 3・6 節。

- 端末は、対数の固定の桶のヒストグラムに集め、60 秒ごとと `visibilitychange` で `sendBeacon` で送る。次元は Action の ID、app、ブラウザ、OS、ワークスペースの大きさの帯、版（直近 3 版）。操作の遅延と伝播は端末の 10% を抜き取る。
- 送るのは数と ID だけで、タイトル・識別子・ワークスペースの ID を送らない。
- 収集の口はセッションで認証し、端末ごとに絞り、値と次元を確かめる。AMP には少ない次元で、細かな分析は S3 の Parquet と Athena で。
- Writer は COMMIT の直前の時刻を `sync_outbox.committed_at` に書き、Relay と Gateway が `deltas` の範囲に `c` として運ぶ。`pong` に Gateway の受けと返しの時刻を入れ、端末は NTP と同じ式で時計の差を見積もる。`catch_up`・ブートストラップ・RTT 200ms 超・背景のタブは数えない。
- サーバーの区間は各タスクの時計で `c` からの経過を測る。
- 合成監視の 2 つのヘッドレスの同期のクライアントを、同じプロセス（同じ時計）で動かし、伝播の SLI の正本の 1 つにする。
- 2 を採らない理由：利用者の端末の情報を外部の事業者へ送ることになり、法務の L2 の外部送信の規律の対象が広がる。事業者の SDK の重さが入力の経路の予算を食う。
- 3 を採らない理由：自前の印（Action の ID）とヒストグラムの形に合わせる手間が大きく、送り先が AWS の別の口になる。自前の口と比べた利点が小さい。
- b を採らない理由：実際の利用者の回線・端末・ワークスペースの大きさの違いが見えない。
- c を採らない理由：端末の IndexedDB の保存と適用（予算 150ms）が測れない。

## Consequences

- 良くなること：
  - NFR-001・002 を、実際の利用者と合成監視の両方で測れる。
  - 区間ごとの遅れが分かる。
  - 端末の情報が外部の事業者へ出ない。
- 引き受けるコスト：
  - 収集の口と集計を自前で持つ。
  - 時計の差の見積もりに RTT/2 の誤差がある。
  - `deltas` と `pong` の形に項目が増える（sync-engine の領域への依頼）。

## Confirmation

- 例示テスト：仮想の時計での時計の差の見積もりの誤差。
- 計装の検査：RUM の送信の中身に、テストのデータの中身が現れない。
- E12：合成監視と RUM の伝播の p99 の差を見て、計測の誤りがないことを確かめる。
