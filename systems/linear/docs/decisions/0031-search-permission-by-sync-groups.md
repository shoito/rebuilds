# ADR-0031: 検索の権限は同期グループで効かせる。文書に行の `sync_groups` を入れ、検索のたびに呼んだ人の購読を条件にし、結果を Aurora で読み直して今の `sync_groups` と削除で落とす。抜粋は版が同じときだけ返す。画面は手元の検索を先に出し、サーバーの結果を後から足す

## Context

非公開のチームのイシュー・コメントは、メンバーでない人に、検索を含むどの経路でも届いてはならない（[ADR-0004](0004-tenancy-and-permissions.md)、NFR-008）。この題材の権限は、同期グループで配る前に絞る（AGENTS.md）。行はそれぞれ `sync_groups` を持ち、各人の購読は `can()` から Writer が決める（[ADR-0013](0013-sync-group-changes-retention-and-reset.md)）。

検索の索引（[ADR-0030](0030-search-engine-opensearch.md)）は、変更から数秒遅れる。その間に次のことが起きうる。

- イシューが公開のチームから非公開のチームへ移った。索引の文書の `groups` はまだ前のチーム。
- タイトルから秘密を消した。索引の文書はまだ前のタイトル。

Notion の題材は、ページの ACL を権限キーに変えて文書に入れ、読み直しで判定関数を通す二重の守りにした（Notion の ADR-0023）。

## Options

1. **文書に行の `sync_groups` を入れ、呼んだ人の購読を `terms` の条件にする。結果を Aurora で読み直す**
2. 同期グループとは別の権限キー（チーム、利用者）を文書に入れる
3. 検索の結果を、後から `can()` で落とすだけにする

手元とサーバーの組み合わせ：

- a. **手元（M2 のタイトルと識別子）の結果をすぐに出し、サーバーの結果を下に足す**
- b. サーバーの結果だけを出す

## Decision

1 と a を採用する。詳細は [search.md](../architecture/search.md) の 6・8 節。

- 文書の `groups` は、行の `sync_groups` と同じ値。権限の別の形を持たない。
- `buildSearchRequest` だけが問い合わせを作り、`routing`・`workspace_id`・`groups`（呼んだ人の今の購読。検索のたびに `sync_subscriptions` から読む）・`trashed`・`deleted` の条件を必ず付ける。
- メンバーシップ・非公開への切り替えは、文書を書き換えず、呼んだ人の購読の側で次の検索から効く。移動は文書を書き直す（p95 10 秒）。
- 結果は Aurora の reader で、RLS の下で読み直し、今の `sync_groups` が購読と交わらないもの、削除・ゴミ箱を落とす。抜粋は、文書の版が行の版と同じときだけ返す。応答は ID と抜粋だけで、タイトルなどはクライアントが手元のモデル（か遅延の読み込み）で描く。
- 合計の件数を返さない。
- 画面は、手元の識別子とタイトルの一致をすぐに描き、150ms 入力が止まったらサーバーに問い合わせ、手元にない結果を下に足す。オフラインは手元だけ。
- 2 を採らない理由：同期グループと検索で権限の形が 2 つになり、ずれが漏れになる。同期グループの判定は既に 1 か所で試験している。
- 3 を採らない理由：件数・並び・ページングに、見てよくない文書が影響する。1 ページが空になる。
- b を採らない理由：1 打ごとの結果が NFR-001 の予算に収まらない。オフラインで検索できない。

## Consequences

- 良くなること：
  - 検索の権限が、同期・遅延の読み込み・ビューの問い合わせと同じ値で決まる。
  - 権限の取り消し（脱退、非公開への切り替え）は、次の検索から即時に効く。
  - 索引の遅れの間も、移動と書き換えの前の中身が漏れない。
- 引き受けるコスト：
  - 検索のたびに購読の読み出しと、結果の読み直し（最大 60 行）が Aurora の reader に増える。
  - 読み直しで落ちた分、1 ページの件数が減りうる。
  - 抜粋が出ない結果がある（索引が追いつくまで）。

## Confirmation

- 性質ベーステスト：PROP-SEARCH-001（組み立て）、PROP-SEARCH-002（索引の遅れを含めて、見てよいものだけ）。
- 本番：`search_hydration_drop` を監視する。移動の直後以外で出たらバグとして扱う。
- 合成監視：「イシューを非公開のチームへ移す → 前のチームの人の検索に出ない」。
