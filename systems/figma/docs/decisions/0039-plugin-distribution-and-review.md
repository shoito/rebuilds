# ADR-0039: 組織の中のプラグインは審査なしで配り、公開のプラグインは初回と権限の拡大で人が審査する。バージョンは不変に保存し、停止のスイッチを持つ。ウィジェットは別の ADR にする

## Context

プラグインを誰に、どう配るかを決める。問題は次のとおり。

- 公開のプラグインは、多くの組織の利用者が動かす。悪意のあるコードや、乗っ取られた作者のアカウントからの更新が、一度に広がる。
- 組織の中だけで使うプラグインまで審査すると、社内の道具を作る速さを落とす。
- 本家は 2019 年に、サンドボックスの脆弱性の報告から 11 日で、プラグインの公開を止め、実行の環境を替え、公開を再開した（[An update on plugin security](https://www.figma.com/blog/an-update-on-plugin-security/)、2019-10-02、2026-09-27 に確認）。すべてを止める手段が要る。

本家は、公開のプラグイン・ウィジェットを初回だけ審査し（通常 5〜10 営業日）、承認後の更新は審査しない（[Publish widgets to the Figma Community](https://help.figma.com/hc/en-us/articles/4410337103639-Publish-widgets-to-the-Figma-Community)。検索結果の要約で確認）。OAuth のアプリでは、private のアプリは審査なし、public のアプリは審査する（[OAuth apps](https://developers.figma.com/docs/rest-api/oauth-apps/)）。いずれも 2026-09-27 に確認。

## Options

1. **組織の中は審査なし。公開は初回と権限の拡大で人の審査、すべての更新で自動の検査**
2. **本家と同じ：公開は初回だけ人の審査**
3. **すべてのバージョンを人が審査する**

## Decision

1 を採用する。詳細は [plugins.md](../architecture/plugins.md) の 8〜10 節。

- **段階は 3 つ：開発中（本人だけ）、組織の中、公開。** 組織の中の公開は、組織の管理者が承認し、運営の審査はない。
- **公開の審査**：
  - すべてのバージョンに自動の検査（manifest、`networkAccess` と `reasoning`、大きさ、既知の悪意のあるコード、ログイン画面に似た入力欄）。
  - 人の審査は、初回と、`permissions`・`networkAccess` が広がる更新、自動の検査が指摘したバージョン。目標は 5 営業日。担当は Ops の配下の「プラットフォームの審査」。
- **バージョンは不変。** コードは S3 に `{plugin_id}/{version_id}/{sha256}` で置き、ホストは読み込んだバイト列のハッシュを照らす。組織の管理者は、許可リストでバージョンを固定できる。
- **停止のスイッチ**：`plugin_blocklist`（プラグイン全体か、特定のバージョン）を Realtime で配り、動いているプラグインを閉じる。5 分以内に全クライアントで止まることを目標にする。加えて、全プラグインを止める ops フラグを持つ。
- **ウィジェットは、この ADR の範囲に入れない。** ファイルを開いた全員の端末でコードが動くので、同意と通信の制限を別に決める。
- 2 を採らない理由：作者のアカウントの乗っ取りや依存のライブラリの汚染による更新が、審査なしで全利用者に届く。権限と宛先の拡大だけを人が見れば、審査の量を抑えつつ、被害の大きい変化を止められる。
- 3 を採らない理由：審査の量が更新の数に比例し、修正の配布を遅らせる。

## Consequences

- 良くなること：
  - 社内の道具は、審査を待たずに配れる。
  - 公開のプラグインで、被害の範囲を広げる更新は人の目を通る。
  - 脆弱性や悪意のあるプラグインを、全クライアントで素早く止められる。
- 引き受けるコスト：
  - 審査の担当と道具を運用する。
  - 権限を広げない悪意のある更新（宣言済みの宛先へ送る中身を増やす）は、自動の検査に頼る。
  - 組織の中のプラグインの品質と安全は、その組織の管理者の責任になる。利用規約に書く（法務）。

## Confirmation

- 結合テスト：`plugin_blocklist` に入れてから 5 分以内に、動いているプラグインが閉じ、以後読み込まれない。
- 結合テスト：`networkAccess` を広げたバージョンは、人の審査が終わるまで、利用者に配られない。
- 結合テスト：ハッシュが `plugin_versions` と合わないコードを、ホストが読み込まない。
- 計測：審査の待ちの日数、自動の検査の指摘の件数、停止のスイッチの到達の時間。
