# YouTube

利用者が投稿した長い動画を、日本の視聴者に大きな規模で配る動画の共有のプラットフォームを、「数 GB・数時間のファイルの再開できるアップロードと、自前で指揮する変換のパイプライン」「動画ごとに決めるビットレートのラダーと、H.264・AV1 のコーデックの組」「CMAF の HLS・DASH と、プレイヤーの ABR、CDN の多層のキャッシュ」「LL-HLS のライブ配信とライブチャット」「不正に強い視聴回数と、遅れて確かめる計測」「権利者の参照と、自前の音声・映像の指紋による著作権の照合」として作り直す設計。日本を最初の市場にする。
