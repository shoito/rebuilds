# ADR-0061: 創作者の機能を標準・中間・上級の 3 つの段に分け、中間は電話の確認、上級はチャンネルの履歴か身元の確認で開く。違反は最初は警告、その後は 90 日で失効する strike にし、ガイドラインと著作権で別に数え、アカウントのステートマシンの効き目を `can()` と `playable()` に渡す

## Context

- 長い動画とライブは悪用（偽の配信、詐欺、侵害）の量を増やす。本家は、電話の確認で 15 分を超える動画・ライブ・独自のサムネイルを、チャンネルの履歴か身元・動画の確認で収益化の申し込み・ライブの埋め込み・Content ID の異議などを開く（[Access features on YouTube](https://support.google.com/youtube/answer/9890437)、2026-10-10 に確認）。
- 本家の違反の扱い：最初は警告、1 回目の strike は 1 週間・2 回目は 2 週間の投稿の停止、90 日に 3 つで終了、各 strike は 90 日で失効（[Community Guidelines strike basics](https://support.google.com/youtube/answer/2802032)）。著作権の strike は 90 日に 3 つで終了の対象、研修の後 90 日で失効、取り下げか反論の通知で解ける（[Copyright strike basics](https://support.google.com/youtube/answer/2814000)）。どちらも 2026-10-10 に確認。
- 措置の効き目（投稿の停止、配信の停止、全動画の非公開）は、Studio、アップロード、ライブ、`playable()` の多くの経路にまたがる。
- 繰り返しの侵害と削除の申出の手続きは**法務の確認待ち：L1・L2**。

## Options

1. **本家の段と strike の形に寄せ、`creator_tiers` と `account_standing` のステートマシンを持ち、効き目を `can()` と `playable()` の入力にする**
2. 段を持たず、すべての創作者にすべての機能を開き、違反ごとに個別の措置だけを行う
3. 違反の点数（重みつきの累計）で段階の措置を決める

## Decision

1 を採用する。詳細は [accounts-and-safety.md](../architecture/accounts-and-safety.md) の 7・9 節。

- 段：標準（チャンネルを作る、有効なガイドラインの strike なし）、中間（電話の確認。1 つの番号で 1 年に 2 チャンネルまで）、上級（中間の後 60 日・strike なし・直近 90 日の確定の視聴 1 以上、または外部の身元の確認）。ガイドラインの strike の間は中間と上級を止める。
- 違反：最初はガイドラインの警告（研修の後 90 日で失効）。strike は発行から 90 日で失効。ガイドラインは 1 回目 7 日・2 回目 14 日の投稿の停止、90 日に 3 つで終了の候補（運用者の確認と異議の期間の後に終了）。著作権の strike は削除の申出に基づく削除だけから出し、照合の一致は strike にしない。重い違反は即時の終了。
- 状態：`account_standing`（`good`・`warned`・`restricted`・`termination_pending`・`terminated`）をチャンネルごとに持つ。`can()` が停止の機能を拒み、`playable()` は終了したチャンネルの全動画に `deny`（`channel_terminated`）を返し、配信の停止を出す（[ADR-0027](0027-takedown-deny-list-within-60s.md)）。
- 終了の前の異議の期間（案：30 日）、通知の文言、関連するチャンネルへの効き目は**法務の確認待ち：L1**。

### 他の案を選ばなかった理由

- **2（段なし）**：使い捨てのアカウントで長い侵害の動画と詐欺の配信が増える。電話の確認は使い捨ての費用を上げる。
- **3（点数）**：創作者に分かりにくく、本家に慣れた創作者の期待とずれる。異議の単位も曖昧になる。

## Consequences

- 良くなること：
  - 措置の効き目が 2 つの関数に集まり、経路ごとの漏れを防げる。
  - 創作者が本家と同じ感覚で状態を理解できる。
- 引き受けるコスト：
  - 電話の確認の SMS の費用と、身元の確認の事業者との契約。
  - 終了したチャンネルの動画の数が多いとき、拒否の鍵の置き場を使い切らない扱い（直近に再生のあった動画だけに置く）が要る。

## Confirmation

- PROP-ACC-003（strike の発行・失効・取り下げの列で状態が決定表と一致）、DT-ACC-002（89・90・91 日の境）、DT-ACC-003（段 × 機能 × strike）。
- 結合：終了の決定から 60 秒でチャンネルの全動画のエッジの 403（見張りの措置と同じ測り方）。
