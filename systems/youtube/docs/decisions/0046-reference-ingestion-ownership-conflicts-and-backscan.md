# ADR-0046: 参照は同じパイプラインで指紋を作り、長さ・汎用の素材・同じ権利者・他の権利者の検査を経て有効にする。所有の衝突は権利の地域が重なるときだけにし、新しい参照の遡りは 1 時間ごとにまとめて、公開から 90 日の動画と視聴の多い動画に当てる

## Context

- [ADR-0008](0008-fingerprinting-and-match-engine.md) は、新しい参照が別の権利者の参照と一致したら所有の衝突の待ち行列に入れ、解くまでブロックを効かせないこと、新しい参照を公開から 90 日の動画と視聴の多い動画に遡ることを決めた。
- 本家の Content ID は、権利者に頻繁に上がる素材の独占的な権利を求め、方針を国・地域ごとに変えられる（[How Content ID works](https://support.google.com/youtube/answer/2797370)、2026-10-10 に確認）。同じ録音でも、国ごとに権利者が違うことがある。
- 参照に、試験のパターン・無音・誰でも使える素材が含まれると、関係のない動画に一致が出る。

## Options

所有の衝突：

1. **権利の地域が重なるときだけ衝突にする**
2. 地域によらず、他の権利者の参照との一致は全部衝突にする

遡り：

- a. **1 時間ごとにまとめ、対象の動画の指紋を小さな索引に流す**
- b. 参照ごとにすぐ遡る

## Decision

1 と a を採用する。詳細は [copyright-matching.md](../architecture/copyright-matching.md) の 9 節。

- 参照の状態：`uploaded → fingerprinting → checking → active | conflict | rejected`、`active ⇄ inactive`。パイプラインの run の種類 `reference`（`probe` と `fingerprint` だけ）。
- 検査：情報のある 30 秒以上・6 時間まで。汎用の素材との一致の区間は除外にし、80% 以上なら `rejected`。同じ権利者の重複は警告。他の権利者の有効な参照との一致で地域が重なれば `conflict`。
- 衝突の区間の一致は解決まで追跡だけ。両方に知らせ、30 日で解決しなければ運用の担当が仲立ちする。
- 遡り：1 時間ごとに有効になった参照で小さな索引を作り、公開から 90 日の動画と 30 日の確定の視聴が 1 万以上の動画の指紋を流す。一致は公開の後の申し立てとして方針を当てる。
- 参照のファイルと指紋は照合のほかに使わない（**法務の確認待ち：L8**）。

### 他の案を選ばなかった理由

- **2（全部を衝突）**：国ごとに権利者が違う正当な登録が衝突になり、待ち行列が溢れる。
- **b（すぐ遡る）**：参照の取り込みの集中で、遡りの読み出しが何度も重なる。1 時間の遅れは権利者に十分短い。

## Consequences

- 良くなること：
  - 地域ごとの権利者を正しく扱える。
  - 汎用の素材での誤った一致を参照の段で防げる。
- 引き受けるコスト：
  - 汎用の素材の集まりを、許諾の確かな素材で作り続ける。
  - 90 日より古く視聴の少ない動画は、新しい参照で照合されない（S2 で検討）。
