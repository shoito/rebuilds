# ADR-0070: PR の CI に黄金の動画の小さな集まり（20 本）の関門を置き、符号化・ラダー・パッケージ・マニフェスト・プレイヤーに触れる変更は通らなければマージしない。メディアの面は「足してから抜く」でデプロイし、Web のプレイヤーは 1%・10%・50%・100% の段でプレイヤーのバージョンごとの QoE で自動に止め、アプリは最低のバージョンを再生の API で強制できるようにする

## Context

- この題材で最も危ないのは、エラーにならずに画質が少し落ちる・再生がときどき止まる誤りである（[quality.md](../quality.md) の冒頭）。符号化とパッケージの誤りは、特定の動画の中身でしか表に出ない。
- 夜間だけの検査では、誤った変更が main に入り、デプロイの後に気づく。全集まり（200 本）を PR ごとに回すと CI が長くなる。
- 作業者のプールは区切りの作業を持ち、`live-transcoder` は最長 12 時間の配信を持ち、`match-engine` は索引をメモリーに持ち、`origin-cache` は NVMe の中身を持つ。一斉の入れ替えは作業・配信・照合・ヒットの率を失う。
- [runbooks/](../runbooks/README.md) の 3 節は、Web のプレイヤーの段（1%・10%・50%・100%、各 24 時間）と止める条件（前の 1.2 倍）を決めた。
- 形式とラダーと規則はフラグにしない（AGENTS.md）。

## Options

1. **PR に小さな集まりの関門、夜間に全集まり。部品ごとの「足してから抜く」。プレイヤーは成果物の段の配布とバージョンごとの QoE**
2. 黄金の動画は夜間だけ。デプロイは一斉のローリング。プレイヤーは `release.*` のフラグで切り替える

## Decision

1 を採用する。詳細は [delivery.md](../architecture/delivery.md) の 2〜5 節。

- **関門**：小さな集まり 20 本を全段で符号化し、ラダーの下限、前との比べ（平均の VMAF −1・ビットレート +5% で止める）、決定性、継ぎ目、音声と映像のずれ、パッケージの適合、マニフェストの黄金の出力、ヘッドレスのブラウザーでの再生を確かめる。CI の専用の Spot の群れで約 12 分。夜間は 200 本、型ごとの決定性、端末の試験、ファジング。合否の値の変更は QA の承認。
- **メディアの面**：作業者のプールは新しい作業者を足し、古い作業者の取得を止めて手持ちが終わってから止める。`live-transcoder`・`live-origin` は配信中を止めず新しい配信だけ新しい側へ。`match-engine` は AZ ごとに外し、照合の一致を抜き取りで確かめて戻す。`origin-cache` は 1 ノードずつ、ヒットの率が戻るのを待つ。エッジの関数は CloudFront のステージングのディストリビューションで、見張りの再生と見張りの措置を通してから昇格。
- **Web のプレイヤー**：バージョンごとの不変の URL。再生の API の `player_cfg` が端末の識別子のハッシュでバージョンを選ぶ。バージョンごとの QoE（[observability.md](../architecture/observability.md) の `player_version` の切り口）が前のバージョンの 1.2 倍を超えたら自動で止めて戻す。
- **アプリ**：ストアの段階の配布。再生の API が `X-<Brand>-Client` のバージョンを見て `min_supported` より古いバージョンに `upgrade_required` を返す。`min_supported` は利用の割合 1% 未満のバージョンだけ上げる（脆弱性を除く）。

### 他の案を選ばなかった理由

- **2**：静かな画質の誤りが main とデプロイに入る。一斉の入れ替えは配信中のライブを切り、照合の写しを同時に失う。プレイヤーのバージョンを `release.*` で切り替えると、フラグの組み合わせで試験が増え、30 日で消す規則とも合わない。

## Consequences

- 良くなること：
  - 符号化とパッケージの誤りを、マージの前に止められる。
  - デプロイで作業・配信・照合・ヒットの率を失わない。
  - プレイヤーの退行をバージョンごとの QoE で数時間のうちに止められる。
- 引き受けるコスト：
  - PR の CI に約 12 分と、専用の群れの費用。
  - `live-transcoder` の古い作業者が最長 12 時間残る。
  - `min_supported` の運用（古いアプリの割合を見る）。

## Confirmation

- 夜間の黄金の動画の失敗 0 を指標として見る（[delivery.md](../architecture/delivery.md) の 9 節）。
- デプロイの試験：staging で配信中のライブを持ったまま `live-transcoder` を入れ替え、欠けがない。
