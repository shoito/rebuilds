# ADR-0022: Web と Android の ABR は、開始の間は回線の推定、その後はバッファの量の写像（貯め 8 秒、緩め 32 秒）で段を選ぶ。バッファ 12 秒未満では推定で頭を抑え、間に合わない取得は捨てて下の段で取り直す。低遅延のライブは回線の推定と再生の速さの調整で選ぶ

## Context

- [architecture/README.md](../architecture/README.md) の 6 節は、Web と Android を自前の ABR にし、開始は回線の推定、安定してからはバッファの量で決める（バッファに基づく形を主にする）とした。iOS は AVPlayer に任せる。
- 回線の推定だけの ABR は、推定の揺れ（携帯の回線、混んだ Wi-Fi）で段が上下し、推定が外れると止まる。バッファだけの ABR は、開始の直後にバッファが薄いので、最下段から長く上がれない。
- 日本の視聴は、電車のトンネルと駅で帯域が急に落ちる場面が多い（[quality.md](../quality.md) の 2.2.1 節 B の回線の記録）。
- ライブの低遅延のモードは、バッファが 1〜3 秒しかない（[ADR-0006](0006-live-ingest-and-latency.md)）。

## Options

1. **開始は回線の推定、定常はバッファの写像、非常の頭と捨てる規則を足す混ぜた形**
2. 回線の推定だけ（推定 × 安全の係数）
3. 学習した方策（強化学習など）

## Decision

1 を採用する。値と模擬の例は [playback-and-abr.md](../architecture/playback-and-abr.md) の 5 節。

- 写像 `f(B)`：`B ≤ 8 秒`は最下段、`8 < B < 40 秒`は最下段から最上段へ直線、`B ≥ 40 秒`は最上段。
- 開始：最初の 1 セグメントは推定 × 0.6、その後は推定 × 0.7 以下の最上段。`f(B)` が今の段以上になったら定常へ移る。
- 定常：`f(B)` が 1 つ上の段以上なら `f(B)` 未満の最上段、1 つ下の段以下なら `f(B)` を超える最下の段、それ以外は今の段。
- 非常：バッファ 12 秒未満で、推定 × 0.9 を超える段を選ばない。
- 捨てる規則：取得の経過が半セグメント以上で、残りの予測の時間がバッファ − 8 秒を超えたら、捨てて測った速さ × 0.8 以下の段で取り直す。
- 推定：セグメントごとの速さの指数の移動平均（α 0.5 と 0.2）の小さいほう。最初の推定は端末に残した前回の値（24 時間）、なければ 1.5 Mbps。
- バッファの上限：60 秒（携帯の回線は 30 秒）。
- 低遅延のライブ：推定 × 0.7 以下の最上段。推定は、すでにでき上がっていた部分（最初のバイトまで 50 ms 未満）の取得だけで測る。目標の遅れに 0.95〜1.05 倍の再生の速さで合わせる。
- 判断の部分（`abr-core`）は時計とネットワークを外から渡す純粋なコードにし、Web と Android と `abr-sim` で同じ試験のベクトルを通す。値の変更は ABR のバージョンとして出し、フラグで切り替えない。

### 他の案を選ばなかった理由

- **2（回線だけ）**：トンネルの前の高い推定で高い段を選び、トンネルの中で止まる。段の上下が多い。
- **3（学習した方策）**：説明と試験が難しく、模擬と本番の差で静かに悪くなる。MVP の後に、1 の結果を基準に比べる。

## Consequences

- 良くなること：
  - 推定の揺れに引きずられず、トンネルのような急な落ち込みを厚いバッファで受けられる（模擬の例で 50 秒の 0.6 Mbps に再バッファ 0 回）。
  - 開始は速い段で始め、開始の時間（NFR-003）を守る。
- 引き受けるコスト：
  - 最上段に届くまでに時間がかかる（模擬の例で約 26 秒）。
  - バッファを厚く持つので、途中で離れた視聴のぶん、捨てるバイトが増える。携帯の回線では上限を 30 秒にする。

## Confirmation

- 性質ベーステスト：PROP-ABR-001〜004（[playback-and-abr.md](../architecture/playback-and-abr.md) の 12 節）。
- `abr-sim`：回線の記録 500 本（PR）・5,000 本（夜間）で NFR-003・NFR-004 を満たし、前のバージョンより再バッファの割合が 10% 以上悪くならない（[quality.md](../quality.md) の 2.2.1 節 B）。
