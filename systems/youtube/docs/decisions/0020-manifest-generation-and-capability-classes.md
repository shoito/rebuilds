# ADR-0020: マニフェストは端末の対応を「能力の組」（コーデック × 段の上限 × DRM、形式ごと）に丸め、組ごとに CDN でキャッシュする。段の帯域の値はセグメントの索引から計算する

## Context

- [ADR-0004](0004-cmaf-packaging-and-drm-scope.md) は、マニフェストを要求の時に作り、端末の対応（AV1 の復号、画面の大きさ、HDR）を再生のトークンから読み、段を選び、VOD は 1 時間キャッシュすると決めた。
- 端末ごとに別のマニフェストを作ると、CDN で共有できず、マニフェストの要求がすべてオリジンに来る。再生の開始（NFR-003）に効く。
- 画面の小さい端末に 1080p の段を見せると、ABR が高い段を選び、配信の費用が増えるのに画質の差は見えない（[ADR-0015](0015-per-title-ladder-convex-hull.md) の `mobile_top`）。
- `BANDWIDTH` の値が実際より小さいと、プレイヤーが高すぎる段を選んで止まる。

## Options

1. **能力を少数の組に丸め、組をパスに入れて CDN でキャッシュする**
2. 端末ごとに作り、キャッシュしない
3. 全段を載せた 1 つのマニフェストにし、選ぶのはプレイヤーに任せる

## Decision

1 を採用する。詳細は [packaging-and-drm.md](../architecture/packaging-and-drm.md) の 5 節。

- 能力の組：コーデック（`h`：H.264 だけ、`a`：AV1 と H.264）× 段の上限（`m`：`mobile_top` まで、`1080`、`2160`）× DRM（`d` の有無）。形式（HLS・DASH）はパスの末尾で分ける。
- 再生の API が組を決めてトークンに入れ、マニフェストのパスにも入れる。エッジはトークンの組とパスの組が同じことを確かめる（[ADR-0025](0025-edge-token-signing-and-cache-keys.md)）。
- 段の選び方：有効な世代の `ready` の段から、コーデック・上限・DRM で絞る。最下段は必ず残す。
- HLS は `EXT-X-VERSION:7`、`EXT-X-INDEPENDENT-SEGMENTS`、`EXT-X-MAP`、`EXTINF` は実際の長さ。DASH は `SegmentTemplate` と `SegmentTimeline`。
- `BANDWIDTH` は索引の 1 セグメントの最大のビットレート＋音声、`AVERAGE-BANDWIDTH` は平均。
- セグメントの URI は相対のパスにし、マニフェストの本文に利用者ごとの値を入れない。
- 期限：VOD のマニフェスト 1 時間。世代の切り替え・段の追加・措置で無効にする。

> 2026-10-10 の注記：マニフェストの URL に形式の番号 `mf` を入れる（`/t/{token}/m/{mf}/{video_id}/{caps}/...`。[ADR-0071](0071-encoder-pinning-reencode-and-manifest-format-versions.md)）。出力のバイトを変える変更で同じ URL に違う中身が混ざらないようにするため。


### 他の案を選ばなかった理由

- **2（端末ごと）**：CDN で共有できず、オリジンのマニフェストの要求が視聴の開始の数だけ来る。
- **3（全段を 1 つに）**：AV1 を復号できない端末が AV1 の段を選びうる（HLS の `CODECS` を正しく見ない古い端末）。電話に 1080p を見せることになる。

## Consequences

- 良くなること：
  - マニフェストを CDN で共有でき、外れの時もオリジンは組の数（最大 32 本）だけ作る。
  - 画面の小さい端末の配信のビットレートを、画質を落とさずに抑えられる。
- 引き受けるコスト：
  - 利用者が画質を手で選ぶときは、上限を外したトークンを取り直す。
  - 新しい能力（HDR など）を足すと組が増える。足すときはこの ADR を更新する。

## Confirmation

- 性質ベーステスト：PROP-PKG-002（組の条件、最下段を残す）、PROP-PKG-003（同じ入力から同じバイト）。
- 表駆動テスト：DT-PKG-001。
- 適合の検査：HLS の検査の道具と `dash-conformance` を夜間に通す（[quality.md](../quality.md) の 2.2.1 節 A）。
