# ADR-0033: プレビューは画像と動画と PDF の 1 頁目のサムネイルだけを確定の後に先に作り、他は見たときに作る。キャッシュは S3 のリビジョンのキーに、変換器のバージョンを `kind` に含めて置き、内容のハッシュで別のリビジョンと使い回さない。配信は `can()` の後に、CloudFront の署名つき URL（10 分、共有リンクは 5 分）で `<brand>usercontent.<domain>` から返す

## Context

[ADR-0007](0007-block-storage-layout-on-s3.md) は、プレビューのキャッシュを `p/<tenant_id>/<rev_id>/<kind>` に置き、90 日で消すと決めた。NFR-011 は、サムネイルを最初 p95 2 秒、キャッシュから p95 200ms で返すことを求める。

決めることは次である。

- すべてのリビジョンに先に作るか、見たときに作るか。S1 の新しいデータは 1 日に保存の 0.3%（約 40 TB）で、すべての文書を先に変換すると費用が大きい。
- 変換器を直したとき、古い出力をどう扱うか。
- 同じ中身の別のリビジョン（コピー、移動、カメラのアップロードの重複）で、出力を使い回すか。テナントの中で使い回すと、作り直しの速さの違いから、読めない名前空間に同じ中身があることを推測されうる（[ADR-0003](0003-dedupe-scope-and-privacy.md) と同じ形の漏れ）。
- 配信の URL の期限と、権限の取り消しの効き。

## Options

作る時：

1. **画像・動画・PDF の 1 頁目のサムネイル（200 MiB 以下）だけを先に、他は見たときに**
2. すべてを先に作る
3. すべてを見たときに作る

使い回し：

- a. **使い回さない（リビジョンごとに作る）**
- b. テナントの中のどのリビジョンとも
- c. 読める名前空間のリビジョンの間だけ

配信：

- x. **`can()` の後に、CloudFront の署名つき URL（10 分、共有リンクは 5 分）**
- y. API が中身を中継する

## Decision

1、a、x を採用する。詳細は [previews-and-thumbnails.md](../architecture/previews-and-thumbnails.md) の 5・8・9 節。

- 先に作るのは、画像・動画・PDF の 1 頁目の 256 px のサムネイル。待ち行列は対話と背景に分け、対話を先に取る。見たときの要求は、なければ `202` と `retry_after_ms` を返す。
- 中身を機械で読む先の処理は、法務の L1 の結論まで `release.eager-thumbnails` の裏に置く。
- `kind` に大きさ・頁と `renderer_version` を含める。変換器を直したら番号を上げ、古い出力は 90 日で消える。リビジョンは不変なので無効化は要らない。
- `preview_entries` を名前空間の表に置き、リビジョンごとに作る。同じ `content_sha256` の別のリビジョンでも使い回さない（`security.md` の 3.5 節と同じ）。
- 配信は `content.<brand>usercontent.<domain>/p/...` の署名つき URL。ヘッダーで種類を固定し、`nosniff` と `CSP: sandbox` を付ける。

### 他の案を選ばなかった理由

- **2（すべて先）**：見られない文書の変換に費用を使う。中身を機械で読む範囲も広がる（L1）。
- **3（すべて見たとき）**：写真のグリッドとカメラのアップロードの一覧で、最初の表示が遅い。
- **b（テナントの中で使い回す）**：作り直しの有無と速さで、読めない名前空間の中身の有無が分かる。
- **c（読める名前空間の間だけ）**：漏れは防げるが、使い回しの判定の索引と、その規則の検証が増える。先に作るのは 256 px のサムネイルだけで、作り直しの費用は小さい。
- **y（API が中継）**：中身が本体のサービスを通る。本体のドメインから中身を返さない規則にも反しうる。

## Consequences

- 良くなること：
  - よく見られるサムネイルは速く、見られない文書には費用を使わない。
  - 変換器の更新で、古い出力を消す作業が要らない。
  - 作り直しの有無と速さから、読めない名前空間の有無を漏らさない。
- 引き受けるコスト：
  - 文書の最初のプレビューは数秒待つ。
  - 同じ中身のコピーでも作り直す。
  - 出した URL は、権限の取り消しの後も最長 10 分使える。

## Confirmation

- 性質ベーステスト：PROP-PREV-001（読めないプレビューを返さない）、PROP-PREV-002（使い回さない）。
- 結合テスト：配信のヘッダー、本体のドメインから中身が返らないこと。
- 本番：サムネイルの p95（最初・キャッシュ）、対話の待ちの長さ、`failed` の理由ごとの数。
