# ADR-0020: S2 の前に、128 KiB 未満のブロックを、テナントと名前空間ごとの 64 MiB の不変のパックに詰める形を用意する。配信は範囲を署名に含めた URL だけにし、パックの全体を読ませない。詰め直しは生きている割合が 50% 未満で行う。有効にするのは `small-block-pack-poc` で費用が下がると確かめたとき

## Context

[ADR-0007](0007-block-storage-layout-on-s3.md) は 1 ブロック 1 オブジェクトを採り、小さなブロックをまとめるパックは S2 の前に測って block-storage の領域で決めるとした。

小さなファイルの多いテナントでは、1 TiB が約 1,070 万オブジェクトになり、PUT・写し・HeadObject の要求が、平均 4 MiB のときの約 40 倍になる（[block-storage.md](../architecture/block-storage.md) の 9 節）。128 KiB 未満は Intelligent-Tiering の監視の外で、Standard に置く。

パックには、重複排除の守り（[ADR-0003](0003-dedupe-scope-and-privacy.md)）と GC の正しさの 2 つの危険がある。

- 署名つき URL でパックの全体を読めると、同じパックの他のブロック（読めない名前空間のもの）を読める。
- パックの中の一部の削除には詰め直しが要り、GC の誤りの余地が増える。

## Options

1. **テナントと名前空間ごとのパック。配信は範囲を署名に含めた URL。S2 の前に計測で有効にする**
2. テナントごとのパック。ブロックごとの鍵で暗号化し、鍵を読める人にだけ渡す
3. パックを持たない（1 ブロック 1 オブジェクトのまま）
4. 小さなブロックの配信をサーバー（ECS）で切り出す

## Decision

1 を採用する。詳細は [block-storage.md](../architecture/block-storage.md) の 8 節。

- 対象は 128 KiB 未満のブロック。`pack-builder` が、名前空間ごとに 64 MiB まで詰めた不変のオブジェクトを作り、索引に `pack_id`・`pack_offset` を足す。元のオブジェクトは GC の手順で消す。
- 配信の URL に範囲 `r=<offset>-<length>` を含めて署名し、CloudFront Functions が `r` から `Range` を作る。利用者の `Range` は捨てる。
- 生きているバイトが 50% 未満のパックは詰め直す。古いパックは索引が指さなくなってから GC の手順（`deleting` を経る）で消す。
- `release.small-block-packing` の裏に置く。有効にする条件は、`small-block-pack-poc` で、要求と保存の費用の和が 20% 以上下がり、範囲の配信の署名が CloudFront Functions で変えられないことを確かめたとき。確かめられなければ、この ADR を `superseded` にして 3 に戻す。

### 他の案を選ばなかった理由

- **2（暗号化したテナントのパック）**：鍵の配布と保管が増え、SSE-KMS とは別の鍵の仕組みを持つことになる（E16 の論点）。
- **3（持たない）**：S2 の量（130 PB）で、小さなファイルの要求の費用を下げる手がない。計測の前に捨てない。
- **4（ECS で切り出す）**：中身がサーバーを通る（[ADR-0001](0001-platform-and-stack.md) の原則に反する）。

## Consequences

- 良くなること：
  - 小さなファイルのオブジェクトの数と要求を、64 MiB のパックの単位に減らせる。
  - 範囲の署名で、読めないブロックの中身を渡さない。
- 引き受けるコスト：
  - 詰め直しの作業と、その GC の検証が増える。
  - 名前空間ごとに分けるので、同じテナントの名前空間をまたぐ重複のブロックはパックに入りにくい。
  - CloudFront の署名と CloudFront Functions の順序は**未検証**で、PoC の結果に採否を預ける。

## Confirmation

- PoC：`small-block-pack-poc` で、費用と、範囲を変えた URL が拒まれることを確かめる。
- 性質ベーステスト：PROP-BLK-001 を、詰め直しを混ぜた列で確かめる。
- 結合テスト：パックの URL で、署名の範囲の外のバイトを取れない。
