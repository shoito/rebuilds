# ADR-0011: 選択型の同期で外したフォルダーは、Synced に「外した」の印を持ち、Local と比べない。名前空間を外された・閲覧に下がったときは、変更のない手元のファイルを消し、手元で変えたものは「`<Brand>` に保存できなかった変更」へ移して上げる

## Context

手元にないことが、削除ではない場合がある。

- **選択型の同期**：利用者が、あるフォルダーを手元に置かないと選んだ（[architecture/README.md](../architecture/README.md) の 6 節）。
- **名前空間を外された**：共有フォルダーから外された。サーバーは `ns_access` を消してから `unmount` を書く（[ADR-0005](0005-namespace-journal-and-cursors.md)）。手元の扱いは sync-engine の領域に残した。
- **役割が閲覧に下がった**：手元の変更を上げられない（[ADR-0006](0006-sync-conflict-model.md) の決定表の 12）。

これらを 3 つの木で表さないと、「手元にないからサーバーから消す」「サーバーにないから手元から消す」の誤りになる。また、外されたときに手元で変えた中身を黙って消すと、中身を失う。

## Options

選択型の同期：

1. **Synced に `excluded` の印を持ち、外した部分を計画から外す**
2. 外したフォルダーを Local に「プレースホルダー」として残し、比べ続ける
3. 外したフォルダーを Remote からも消す（受けない）

外された名前空間：

- a. **変更のないものを手元から消し、変えたものを利用者のルートの「保存できなかった変更」へ移して上げる**
- b. 手元のファイルをすべて残し、同期の外の普通のファイルにする
- c. 手元のファイルをすべて消す

## Decision

1 と a を採用する。詳細は [sync-engine.md](../architecture/sync-engine.md) の 9 節。

- 外したフォルダー F の Synced の行に `excluded` を付ける。F の子孫は Local と比べない。Remote の F の子孫は受け続け、戻したときにすぐ計画できるようにする。
- 外すときは、手元の F の子孫のうち、Local と Synced が同じものだけを消す。手元で変えたものは先に上げる。サーバーへの削除は出さない。
- 外したフォルダーは手元の木に出さない（プレースホルダーとしても出さない）。
- F と同じ親・同じ `name_key` の名前を手元で作ったら、手元のものを `<名前> (選択型の同期の競合)` に移して新しいフォルダーとして上げる。
- `unmount` では、変更のないファイルを OS のゴミ箱を使わずに消す。手元で変えた・作ったものは、利用者のルートの「`<Brand>` に保存できなかった変更/<共有フォルダーの名前>/」へ移して上げ、知らせる。
- 役割が閲覧に下がったら、手元の変更を同じ場所へ移して上げ、手元の元のファイルはサーバーの中身に戻す（決定表の 12）。
- 本家の選択型の同期の競合の扱い・外されたときの手元の扱いは、公開の資料で確かめられなかった（**未検証**）。

### 他の案を選ばなかった理由

- **2（プレースホルダーで残す）**：オンラインのみのファイルと同じに見え、利用者が開いて取り出すと選択の意味がなくなる。木の大きさが NFR-008 の分だけ増える。
- **3（受けない）**：戻したときに番号 0 から読み直す必要がある。Synced の中の外した部分が古くなり、戻したときに誤った衝突を出す。
- **b（すべて残す）**：権限を失った中身が端末に残り続ける。持ち主が外した意味が薄れる。
- **c（すべて消す）**：手元で変えた中身を失う（NFR-004）。

## Consequences

- 良くなること：
  - 外した・外されたで、サーバーから消すことも、手元の変更を失うこともない。
  - 外したフォルダーを戻すとき、Remote が新しいので、すぐ取り出せる。
- 引き受けるコスト：
  - 外したフォルダーの Remote の行を持つ分だけ、DB が大きくなる。
  - 外された共有フォルダーの、手元で変えた中身が利用者自身の名前空間へ上がり、容量に数えられる。利用者に知らせる。
  - `unmount` で消したファイルは OS のゴミ箱に残らない。

## Confirmation

- 表駆動テスト：DT-SYNC-003（9 節の各行）。
- 性質ベーステストとシミュレーター：PROP-SYNC-009（`unmount` の後、手元で変えた中身は「保存できなかった変更」にあり、変えていないファイルは手元にない）。選択型の同期の切り替えの操作を生成器に入れ、PROP-SYNC-001（収束。`excluded` を除く）を確かめる。
