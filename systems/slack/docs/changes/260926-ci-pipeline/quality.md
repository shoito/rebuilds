# Quality: PR の CI、merge queue、仕様の追跡と衝突の検査

- Change: 260926-ci-pipeline
- Spec: [spec.md](spec.md) / Plan: [plan.md](plan.md)
- 題材の品質戦略: [quality.md](../../quality.md)
- 作成の理由: 新しいテスト基盤が必要（`spec.md` のジェネレーター、フィクスチャのモノレポと git の履歴、依存グラフのジェネレーター）。この変更の検査は、以後のすべての変更の品質の関門になるため、検査自体の誤り（見逃し・誤検知）の影響が大きい

## 1. リスク

| リスク | 当たる題材のリスク | 起きると |
| --- | --- | --- |
| 影響の範囲の取りこぼしで、壊れたパッケージのテストが走らずにマージされる | すべて（関門の見逃し） | リスク 1〜3 位の性質ベーステスト（PROP-MSG-*、PROP-WS-*）が、走らないまま `main` に入る |
| 追跡の検査の見逃しで、テストのない要件が `done` になる | すべて | 仕様とテストの結びつきが崩れ、QA の判定の根拠がなくなる |
| 楽観ロックの見逃しで、先の変更の要件が黙って上書きされる | すべて | 承認済みの仕様が失われる（process.md の 8.3 節） |
| 検査の誤検知で、正しい PR が止まる | — | エージェントと人の作業が止まり、検査を迂回する動機が生まれる |
| ruleset の設定の誤りで、保護が効いていない | — | レビューを経ない変更が `main` に入る |

## 2. テスト設計

### 2.1 PROP-DLV-001（影響の範囲）のジェネレーター

- パッケージの数：2〜25。依存グラフは、パッケージに順序を付け、前のパッケージへだけ辺を張ることで循環をなくす。辺の密度は 0〜40%。
- 変更の集合：0〜10 ファイル。パッケージの中のファイル（`src/`、`test/`、`package.json`）、ルートのファイル（DT-DLV-001 の 3 行）、文書（`docs/`）、無関係のファイルを混ぜる。
- 実行：一時ディレクトリに pnpm のワークスペースを生成し、git で起点と変更後の 2 つのコミットを作り、`turbo run test --affected --dry=json`（または代替の `--filter`）の結果を取る。参照の実装は、グラフの逆向きの推移閉包。
- 試行回数：PR で 100 回（1 回に数秒かかるため）、夜間に 1,000 回。反例は `test/fixtures/affected/` に残す。

### 2.2 `spec.md` のジェネレーター（PROP-DLV-002, 003, 004）

- 題材：1〜2。capability：1〜4（`specs/README.md` の接頭辞の表から選ぶ）。
- 変更：0〜6。`status` は 4 つの値と不正な値を混ぜる。各変更の `ADDED`・`MODIFIED`・`REMOVED` に、ID を 0〜8 件。
- ID の番号は、衝突が起きやすいよう 001〜015 の狭い範囲から選ぶ。
- 本文：日本語の文、表、コードブロック（中に `### REQ-...` のような見出しに似た行を含める）、全角の空白、行末の空白、CRLF を混ぜる。
- テストのファイル：ID を名前に含む `it(...)`、コメント、文字列の一部（`REQ-MSG-0010`）を混ぜる。
- 参照の実装：DT-DLV-003・004・005 を素直に書いた関数。`spec.md` の表を読み込む表駆動テストで、参照の実装自体も検査する。
- 試行回数：PR で各 500 回。

## 3. テスト環境とテストデータ

- すべてローカルと CI で動く。GitHub の API を呼ぶもの（ruleset、所要時間、Issue、merge queue の PR のタイトル）は、応答をフィクスチャにしてモックする。
- フィクスチャのモノレポ：`tools/spec-checks/test/fixtures/monorepo/`。`apps/api` → `packages/contract`、`packages/db` の依存を持つ最小の構成。テストの中で一時ディレクトリにコピーし、git の履歴を作る。
- 実際の GitHub の設定（ruleset、merge queue）は、受け入れ試験で 1 回だけ確かめ、結果を PR に記録する。

- PROP-DLV-001〜004 が、2 節の試行回数で反例なく通る。
