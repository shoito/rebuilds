# ADR-0006: メッセージ本文を独自の軽量 AST（JSON）で保存する

## Context

本文にはメンション、チャンネルリンク、URL、絵文字、コードブロックが含まれる。メンション通知や検索のために、これらを構造として取り出す必要がある。

## Options

1. HTML
2. Markdown 文字列
3. 独自の軽量 AST（JSON）

## Decision

3 を採用する。メンションやリンクを構造として扱え、描画時に HTML を組み立てるため、XSS の攻撃面が小さい。

## Consequences

- 良くなること：メンション抽出や検索用のテキスト化が確実になる。
- 引き受けるコスト：入力欄から AST への変換と、スキーマのバージョン管理が必要になる。

## Confirmation

- 性質ベーステスト：任意の AST について、描画結果に `<script>` などの実行可能な要素が含まれない。
