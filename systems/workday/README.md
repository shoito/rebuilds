# Workday

人事（HCM）と給与計算の SaaS を、「有効日付つきで履歴を失わない人事の記録」と「誤りのない日本の給与計算」として作り直す設計。まず日本の企業の人事・給与の担当者、マネージャー、従業員を対象にする。

主な論点：

- 有効日付と履歴（将来日付の変更、訂正、任意の時点の問い合わせ）を持つオブジェクトモデル
- 承認・ルーティング・委任・取消を持つ業務プロセスのエンジン
- 決定的で再現できる給与計算（源泉所得税、社会保険料、住民税、端数の規則）
- ドメインとロールによる権限と職務分掌、マイナンバーの隔離
