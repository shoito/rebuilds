# ADR-0046: 保管庫の API は操作者の主張と保管庫の担当者の表で目的ごとに判定し、平文を外に返さず、記録を番号なしのハッシュの連鎖で残す

詳細は [my-number-vault.md](../architecture/my-number-vault.md) の 5・6・8 節。

## Context

- [ADR-0005](0005-security-and-my-number.md) は、保管庫の API が目的を必須の引数にし、目的ごとに呼べるロール（事務取扱担当者）と返す形を決め、法定の書類は保管庫の中で作り、すべての操作を追記のみの記録に残すと決めた。
- 人事の側と保管庫は別のアカウント。相互 TLS はサービスを確かめるが、「誰の操作か」は確かめない。人事の側の権限の判定を信じるだけだと、人事の側の乗っ取りで、任意の人の名前で番号を表示できる。
- ガイドラインは、アクセス制御を事務取扱担当者に限ること、取扱状況の記録を保存すること、**取扱状況を確認するための記録に特定個人情報を記載しない**ことを求める（[ガイドライン](https://www.ppc.go.jp/legal/policy/my_number_guideline_jigyosha/) の別添 1 の C-b・c と F、2026-09-28 に確認）。
- 監査の記録の改ざんの検知は [ADR-0048](0048-audit-log-hash-chain-and-anchoring.md) で決める。

## Options

判定：

1. **相互 TLS に加え、人事の側が呼び出しごとに署名した操作者の主張（60 秒の JWT）を渡す。保管庫は自分の担当者の表（`mn_handlers`）と目的の表で判定する**
2. 人事の側の権限の判定の結果を信じる（相互 TLS だけ）
3. 事務取扱担当者が保管庫に別のアカウントでログインする（人事のログインと別）

返す形：

- a. **人事の側には `mn_ref`・状態・書類の ID だけを返す。番号の表示は保管庫の画面の中だけ**
- b. 末尾 4 桁を人事の側に返して画面に出す

## Decision

1 と a を採用する。

- 主張の中身：テナント、操作者、代理、目的、対象の `mn_ref`、要求の ID、再認証の時刻。人事のアカウントの KMS の非対称の鍵で署名する。`jti` は 1 回限り。
- 担当者の指定は、人事の側の業務プロセス（起票と別の人の承認）の完了の事象を、署名つきで保管庫が受けて `mn_handlers` に書く。承認の記録のない指定を受けない。教育の実施の記録を条件にする。
- 目的はシステムの表（番号法の事務の範囲）。テナントは足せない。操作は目的の `allowed_ops` に限る。
- `reveal` は保管庫の画面で 60 秒だけ全桁を出し、理由と 5 分以内の再認証を要る。
- 法定の書類は、番号を含まない元のデータを保管庫が受け、保管庫の中で番号を合わせて作り、保管庫の S3 に置く。取り出しは保管庫の画面から。
- 番号は DEK で暗号化し、DEK を保管庫の KMS の鍵で包む。AAD にテナントと `mn_ref`。重複の検知はテナントごとの HMAC。
- 記録 `mn_access_log` は、成功も拒否も、操作と同じトランザクションで追記する。番号・番号の一部・HMAC を入れない。テナントごとのハッシュの連鎖にし、log-archive のコンプライアンスモードの Object Lock に送る。日次に ALB の記録と突き合わせる。
- 2 を採らない理由：人事の側の 1 つの脆弱性が、番号の表示の権限の迂回になる。保管庫を分けた効果が小さくなる。
- 3 を採らない理由：事務取扱担当者の ID の管理が 2 つになり、退職・異動での無効化の漏れが起きる。人事の側の業務プロセス（指定と承認）と結べない。
- b を採らない理由：末尾 4 桁が特定個人情報に当たるかは確認待ち（L47）。当たるなら人事の側の範囲が広がる。人事の画面に出す必要も小さい。

## Consequences

- 良くなること：
  - 人事の側が乗っ取られても、担当者でない人の名前で番号を見ることはできない（主張の署名の鍵と担当者の表の両方が要る）。
  - 取扱状況の記録を、番号を含めずに保存でき、テナントに見せられる。
- 引き受けるコスト：
  - 担当者の指定を人事の側と保管庫の 2 か所に持つ（正本は保管庫の表、起点は人事の業務プロセス）。同期の遅れで、指定の直後に操作できないことがある。
  - 主張の署名の鍵（人事のアカウント）が漏れると、担当者の名前をかたれる。鍵の `Sign` は `api` のタスクのロールだけに与え、CloudTrail で見張る（[security.md](../architecture/security.md)）。
