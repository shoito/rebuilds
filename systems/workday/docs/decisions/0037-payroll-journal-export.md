# ADR-0037: 給与の仕訳を実行の段ごとに釣り合う追記のみの記録にし、部門と勘定に集計して連番の束で出力する

詳細は [payments-and-accounting.md](../architecture/payments-and-accounting.md) の 7 節。

## Context

- [ADR-0004](0004-payroll-engine.md) は、確定した結果から実行ごとに仕訳を作り、借方と貸方の一致をコミットの時に DB のトリガーで確かめ、追記のみで、取消は逆仕訳にすると決めた（Stripe の題材の [ledger.md](../../../stripe/docs/architecture/ledger.md) に倣う）。勘定の対応はテナントの設定で、預り金と法定福利費の扱いは税理士の確認待ち（[intent.md](../intent.md) の L9）。
- 事業主の社会保険料は、納入告知額から被保険者の負担の合計を引いた額で、給与の計算の時点では分からない（[日本年金機構](https://www.nenkin.go.jp/service/kounen/hokenryo/nofu/20121026.html)、2026-09-28 に確認）。
- 会計システムに従業員の単位の行を渡すと、給与の額が経理の利用者と会計システムに広がる。
- 会計システムへの出力は、途中の失敗や再送で二重にも欠けにもならない必要がある。
- 本システムは財務会計を持たない（intent の MVP の外）。仕訳の出力までにする。

## Options

仕訳の単位：

1. **実行の段（確定、事業主の見込み、支払、不能、取消、事業主の調整）ごとの仕訳。行は会社 × 部門 × 勘定 × 元の項目に集計し、従業員の ID を入れない**
2. 従業員ごとの仕訳
3. 月ごとに 1 つの仕訳

出力：

- a. **まだ出していない仕訳を順に集めた連番の束。同じ束は同じバイト列。拒まれても仕訳は直さず、直す仕訳を足す**
- b. 期間を指定して毎回作る出力

## Decision

1 と a を採用する。

- `payroll_journal_entries`（段の種類、会計の日、逆仕訳の元、勘定の対応の版、冪等キー）と `payroll_journal_lines`（勘定、部門、金額。借方が正、貸方が負、0 は禁止）。遅延制約のトリガーで仕訳ごとに合計 0・2 行以上を確かめる。アプリのロールは追記だけ。
- 冪等キーは段から決まる値（`finalize:{run_id}` など）。状態の遷移と同じトランザクションで書く。
- 勘定の対応（`gl_account_maps`）は版を持ち、項目の `gl_mapping_key` から借方・貸方と部門の規則を引く。鍵のない項目があれば確定の前に止める。
- 事業主の社会保険料・雇用保険料は料率からの見込みで計上し、納入告知の額の取り込みで差を調整の仕訳にする。
- 会計の日の既定は支給日。発生の月にする設定を持つ（L9）。
- 部門は期間の末日の主たる職務のコストセンター。日数の按分を選べる（`allocate_largest_remainder`）。
- 出力（`gl_export_batches`）は会社ごとの連番。汎用の CSV とテナントの列の雛形。
- 2 を採らない理由：会計システムと経理の利用者に、従業員ごとの給与の額が広がる（[ADR-0005](0005-security-and-my-number.md) の最小の権限に反する）。行の数も人数に比例して増える。
- 3 を採らない理由：取消・不能・調整を、どの実行のどの段の誤りかで追えない。実行の段と同じトランザクションで書けない。
- b を採らない理由：期間の境目の仕訳の二重・欠けと、同じ期間の 2 回の出力で違う中身になる恐れがある。

## Consequences

- 良くなること：
  - 仕訳が給与の実行の段と 1 対 1 で、取消と調整の経緯が追える。
  - 会計システムに個人の給与の額が渡らない。
  - 出力の再送が安全。
- 引き受けるコスト：
  - 従業員の単位の補助元帳が要る会社には、別のレポート（権限つき）で出す（[reporting.md](../architecture/reporting.md)）。
  - 納入告知の額の取り込みの運用が月に 1 回要る。
  - 科目・計上の時期の確認（L9・L40）まで、既定の対応表の spec を承認しない。

## Confirmation

- DB のテスト：釣り合わない仕訳のコミットが失敗する。アプリのロールの `UPDATE`・`DELETE` が失敗する。
- 性質ベーステスト：PROP-PMT-005（仕訳ごとの釣り合いと未払金の残り）、PROP-PMT-006（束の決定性と重複なし）。
- 決定表のテスト：DT-PMT-004。
- CI：`payroll_journal_lines` のスキーマに従業員の ID の列がないことを検査する。
